> 목적: 지금까지의 결과(패턴 · 패션 적응 불지지, 사전학습 · 구매 기록 · ID 사후 관찰)를 넘어서, **이미지를 "어떻게" 써야 하는가**에 대한 근거를 모으고 가설을 다시 세운다. 수정한 가설은 [가설별실험가이드.md](가설별실험가이드.md) 4절.

## 0. 한 쪽 요약

| 수단 (레버) | 선행 연구가 말하는 것 | 우리 결과 | 우리가 더 볼 것 |
|---|---|---|---|
| **① 인코더 선택** | 최신 멀티모달 인코더(CLIP · ALIGN · BLIP-2)가 ResNet-50보다 대체로 낫지만 **차이는 작고 모델마다 다름** (ID 기반 그래프 모델에서) | ID 없는 모델에서 사전학습에 따라 **약 2배**, 패션 적응은 효과 없음 | 텍스트 정렬 없는 이미지 모델(DINOv2), 모델 크기 |
| **② 학습 방식 (고정 대 미세 조정)** | 인코더를 끝까지 또는 **마지막 2~3층만** 학습해도 크게 오름. 고정 특징 + MLP는 눈에 띄게 낮음 | 고정 임베딩만 사용 | 비용이 커서 이번 범위 밖 → 한계로 서술 |
| **③ 결합 방식** | 텍스트가 학습을 지배해 이미지가 덜 최적화됨(모달리티 불균형). **모달리티 드롭아웃 · 단일 모달 교사 증류 · 게이트/트랜스포머 결합**이 처방. 상품 단위 게이트는 희소 상품에서 시각 의존이 커짐 (VisGate) | 이어 붙이기 한 가지만 사용 | **모달리티 드롭아웃, 늦은 결합 · 게이트** (핵심 빈칸) |
| **④ 표현 · 정규화** | 이미지 임베딩이 텍스트보다 흩어져 있고 정규화가 안 된 경우가 많음 → "인코더별 정규화 · 재조정 필요" | PCA 256 + L2로 맞춤 (그래서 이미지가 쓰였을 가능성) | 정규화를 빼면 기여가 줄어드는지 |
| **⑤ 이미지 → 텍스트 변환** | VLM이 만든 상품 설명이 이미지 기여를 키운다는 보고 vs **캡션보다 VLM 은닉 상태가 낫다**는 보고 (상충) | 안 봄 | 비용 큼, 탐색적 후보 |
| **⑥ ID와의 관계** | ID는 기존 상품에 여전히 강함 → **대체보다 결합**이 낫다. 콘텐츠와 ID를 정렬하는 방법 | 규제 없는 ID는 이미지 기여 약 25% 감소 (사후) | ID 의존 정도별 용량-반응, 강한 ID 모델 |
| **⑦ 적용 대상 (콜드스타트)** | 이미지 효과는 **콜드 상품에서 훨씬 큼** (VBPR 전체 +12% 대 콜드 +28%, PixelRec 콜드 상품 수 배). 오래된 결과 | 희소 · 신규에서 약 2배 (사후) | 재검증 (새 발견은 아님, 확인으로 서술) |
| **⑧ 학습 목표 (인기도 보정)** | 배치 내 부정 샘플은 인기 상품을 과하게 벌줌 → **logQ 보정** | 베이스라인에 크게 짐, 인기도 입력으로도 못 줄임 | logQ 보정으로 격차를 줄여도 이미지 효과가 남는지 |

**핵심 메시지:** 선행 연구는 이미지를 더 잘 쓰는 방법으로 ② 미세 조정, ③ 결합 · 학습 균형, ④ 정규화를 꼽는다. 우리는 ①(인코더)만 체계적으로 봤고 ③ · ④가 비어 있다. **③ 모달리티 드롭아웃과 결합 구조가 "어떻게"의 핵심 빈칸**이고, 비용도 감당할 만하다.

## 1. 출발점: "텍스트가 지배하고 이미지는 덜 쓰인다"

### Ye 외 2025 — Are Multimodal Embeddings Truly Beneficial for Recommendation? 【본문】
- arXiv 2508.07399v2. ID 기반 멀티모달 모델 14개, Amazon Baby · Sports · Clothing, MMRec이 제공하는 ResNet-50 + SBERT 특징, 모달리티를 하나씩 빼는(knockout) 방식
- 결론: 텍스트를 빼면 거의 모든 모델이 크게 떨어지고, 이미지는 덜 활용된다. 단 이미지에 민감한 모델(GRCN −13.6%, LGMRec −11.6%, Clothing NDCG@10)은 이미지를 빼면 떨어진다
- **원인 설명 (5.2절):** "텍스트 신호가 더 배우기 쉬워 학습 중 시각 신호를 덮어버린다", "이미지 임베딩이 텍스트보다 흩어져 있어 학습이 더 어려울 수 있다", 미리 뽑은 텍스트 임베딩은 정규화돼 있고 이미지 임베딩은 아니다
- **제안 (6.2 · 7절):** 시각 효과를 살리려면 "인코더별 정규화나 재조정이 필요할 수 있다", 향후 결합 전략 설계를 탐구하겠다
- 부록 표 12의 ViT 결과는 전체 성능만 보고 (본문 논의 없음)
- **우리에게 주는 것:** 그들의 결론은 (구세대 특징, ID 기반, 기존 상품 평가, 정규화 불일치) 조건에서 나왔다. 이 조건들을 하나씩 바꾸는 것이 우리 논문의 축

### A Reproducibility Study of Multimodal Embeddings for Recommender Systems (Springer, 2026) 【2차】
- 이미지 임베딩만으로는 추가 이득이 제한적이고, VBPR · BM3 · SLMRec 같은 모델은 주로 상호작용 데이터에 의존한다고 보고 (검색 요약). 원문 미확인

### H&M 데이터에서의 기존 관찰 【2차】
- TU Wien 학위논문: H&M에서 미세 조정한 BLIP-2 특징으로 VBPR을 돌렸을 때 텍스트 임베딩이 이미지 · 멀티모달보다 나았다 (검색 요약)
- Goldstein · Hajaj · Alony, ICIS 2024 (Warm Recommendation) 【초록】: H&M 데이터, 이미지 · 텍스트 · 속성 임베딩으로 신규 상품과 가장 비슷한 기존 상품을 찾아 추천. 멀티모달이 단일 모달보다 낫고, 콜드스타트에서 hit-rate 상대 +7%. 선행 버전(SIGDSA 2023)은 텍스트 설명 임베딩이 가장 효과적이라고 보고
- **시사점:** H&M에서도 "이미지는 텍스트보다 약하다"는 관찰이 있다. 우리가 이미지 기여를 크게 본 것은 **ID 없는 모델 · 최신 인코더 · 정규화**라는 조건 때문일 수 있다 → 조건을 명시해야 함

## 2. 레버 ①: 어떤 이미지 인코더를 쓰나

### Large-scale Benchmarks for Multimodal Recommendation with Ducho (arXiv 2409.15857, Expert Systems with Applications) 【본문 일부】
- 추출기: ResNet-50 + SBERT (고전), MMFashion + SBERT (패션 특화), CLIP · ALIGN · AltCLIP · BLIP-2 (멀티모달 설계), ViT + SBERT
- 데이터: Amazon Office · Digital Music · Baby · Toys · Beauty (+ Allrecipes, MovieLens), 모델 9개 (VBPR, GRCN, LATTICE, BM3, FREEDOM, NGCF-M, LGMRec, PGL, COHESION)
- 결과: 멀티모달 설계 추출기가 **일관되게 이기지는 않음**. 모델 · 데이터에 따라 다르고 차이가 작은 경우가 많다 (GRCN에서 CLIP 약 +6%, VBPR · FREEDOM은 1% 미만, LATTICE에서는 CLIP이 약 5% 낮음). ALIGN · BLIP-2가 상위인 경우가 많고, **패션 특화 MMFashion이 다른 설정을 이기는 경우는 드물다**
- **우리와의 관계:** "패션 특화가 이기지 않는다"는 우리 H1 불지지와 같은 방향. 반면 우리는 ID 없는 콘텐츠 모델에서 인코더 차이가 **약 2배**로 훨씬 크게 나왔다 → "인코더의 영향은 모델이 콘텐츠에 의존할수록 커진다"는 해석이 가능 (가설로 세울 수 있음)

### Ducho 2.0 (arXiv 2403.04503) 【초록】
- 특징 추출 프레임워크. CLIP ViT-B/16 지원, MMFashion으로 미세 조정한 ResNet-50 포함

## 3. 레버 ②: 인코더를 고정하나, 함께 학습하나

### MoRec — Where to Go Next for Recommender Systems? ID- vs. Modality-based Recommender Models Revisited (Yuan 외, arXiv 2303.13835, SIGIR 2023 【학회 확인 필요】) 【초록】
- ID 대신 최신 모달리티 인코더로 상품을 표현하는 모델(MoRec)이 "비용이 큰 끝까지 학습(end-to-end)"을 쓰면 기존 상품 추천에서도 ID 기반 모델과 비슷하거나 낫다
- 한계로 단일 모달 인코더, 기본적인 결합 방식만 사용했다고 밝힘

### PixelRec — An Image Dataset for Benchmarking Recommender Systems with Raw Pixels (arXiv 2309.06789) 【본문 일부】
- 이미지 중심 대규모 데이터 (상호작용 약 2억, 사용자 3천만, 표지 이미지 40만)
- **고정 대 미세 조정 (5.5절):** 한 층만 미세 조정해도 크게 오르고, **2~3층 미세 조정이 최적**. 고정 특징 위에 DNN 층을 더해도 "이미지 인코더 미세 조정보다 눈에 띄게 낮다"
- **콜드스타트 (5.2절):** 이미지 모델(PixelNet)이 콜드 상품에서 ID 모델보다 낫고, MF · DSSM · BERT4Rec · SRGNN에서 콜드 상품 성능이 수 배 오름
- **주의:** 기존 상품에서는 MF · **DSSM(Two-Tower)** 기반 PixelNet이 ID 모델보다 유의하게 낮음. 순차 모델에서는 비슷
- **우리와의 관계:** 우리 모델(Two-Tower, 고정 특징)이 베이스라인에 지는 이유 중 하나. 미세 조정은 L4에서 학습 쌍 수백만 개 × 이미지 인코딩이라 3주 일정으로는 어려움 → **한계와 향후 연구**로

### DVBPR — Visually-Aware Fashion Recommendation and Design with Generative Image Models (Kang 외, arXiv 1711.02231) 【초록】
- 패션에서 원본 픽셀로 이미지 표현을 추천과 함께 학습(Siamese CNN). 미리 뽑은 시각 특징을 쓰는 변형보다 낫다고 보고

### End-to-End Image-Based Fashion Recommendation (Elsayed 외, FashionXRecsys 2021 워크숍) 【초록】
- 속성 인식 추천에 이미지 특징(보정한 ResNet-50)을 넣는 세 가지 방식을 비교. 끝까지 학습 여부는 초록만으로 확인 불가

## 4. 레버 ③: 텍스트와 이미지를 어떻게 결합하나

### 결합 시점 분류 — A Comprehensive Survey on Multimodal Recommender Systems (Zhou 외, arXiv 2302.04473) 【2차】
- 이른 결합(원 특징을 바로 합침, 우리 방식) · 중간 결합(은닉 표현을 층마다 합침) · 늦은 결합(모달리티별 예측을 합침). 각 시점 안에서 이어 붙이기 · 어텐션 등

### 모달리티 불균형 — Modality-Balanced Learning for Multimedia Recommendation (CKD, ACM MM 2024, arXiv 2408.06360) 【초록】
- 모든 모달리티를 같은 목표로 최적화하면 **약한 모달리티가 덜 최적화**된다(수렴이 느리거나 성능이 낮음). 저자들은 모든 모달리티가 충분히 최적화되지 않는다고도 관찰
- 처방: **단일 모달 교사 → 멀티모달 학생 증류**, 반사실 추론으로 모달리티별 효과를 추정해 증류 손실을 재가중. 이른 · 늦은 결합 모두에 끼워 쓸 수 있음, 6개 모델에서 개선
- 시각 모달리티의 정보 활용률을 크게 높였다고 보고

### 모달리티 드롭아웃
- **LRMM (Wang · Niepert · Li, EMNLP 2018)** 【2차】: 학습 중 일부 모달리티 표현을 무작위로 지우는 m-drop. 결측 모달리티와 콜드스타트 대응
- **Sequential Modality Dropout (Yang · Zhang, CIKM 2026, arXiv 2608.10240)** 【초록】: 사용자 이력 전체에서 이미지 · 텍스트 흐름을 확률 p로 독립적으로 지움. 4개 모델 × Amazon 4개 영역에서 텍스트 없이도 성능 유지율 1.0~3.2배, **모든 모달리티가 있을 때 정확도 손실은 거의 없음**
- **DropoutNet (Volkovs 외, NeurIPS 2017)** 【초록】: 콜드스타트를 "입력 결측" 문제로 보고, 학습 중 선호 입력을 드롭아웃해 콘텐츠만으로도 작동하게 학습
- **우리와의 관계:** "텍스트가 이미지를 덮는다"(Ye 외)에 대한 가장 직접적이고 싼 처방. 우리 상품 타워에 **텍스트 드롭아웃**만 추가하면 됨. ID 드롭아웃(우리 i1~i4)과 같은 원리

### 트랜스포머 결합 — ItemSage (Pinterest, KDD 2022, arXiv 2205.11728) 【초록】
- 이미지와 텍스트 특징을 트랜스포머로 결합한 상품 임베딩. 단일 모달 대비 크게 우수, 온라인 A/B에서 사용자당 GMV 최대 +7%, 클릭 +11%
- 개인화 쇼핑 추천(사용자 기반 포함)에 쓰인 실서비스 근거

### 게이트 결합 — VisGate: Deciding When to Rely on Visual Information (Glisovic · Kragic · Tegner, CARS @ RecSys 2026, arXiv 2608.10700) 【초록】
- 순차 추천에서 상품 임베딩과 사용자 현재 맥락에 따라 **상품 단위로 시각 정보 사용 여부를 정하는 게이트**
- 시각 정보의 유용성은 고정된 상품 속성이 아니라 상품 · 이력에 따라 달라지는 잠재 변수이고, **상호작용이 희소할수록(협업 신호가 약할수록) 커지며**, **시각적 특이성**과 상관
- 학습된 게이트를 "언제 · 왜 시각 정보가 도움이 되는가"의 **측정 도구**로 쓸 수 있다고 제안
- **우리와의 관계:** 4-4 게이트 결합의 직접 근거. 우리 사후 결과(희소 · 신규에서 기여 큼)와 같은 방향. 게이트 값 α를 구매 기록 · 시각 특이성별로 보면 RQ3와 연결됨

### 정보 인식 결합 — Enhancing Multimodal Recommendations with VLMs and Information-Aware Fusion (Kieu 외, arXiv 2511.02113) 【초록】
- 기존 방법이 "거친 시각 특징과 단순한 결합"에 의존한다고 지적. 부분 정보 분해(PID)에서 착안한 결합 모듈 + VLM 설명 생성으로 **시각 특징의 기여를 크게 높였다**고 보고 (Amazon 3개)

## 5. 레버 ④ · ⑤: 표현 · 정렬 · 이미지를 텍스트로

### AlignRec (Liu 외, CIKM 2024, arXiv 2403.12384) 【2차】
- 콘텐츠 내부 정렬 · 콘텐츠와 ID 정렬 · 사용자와 상품 정렬을 분리한 목표. 콘텐츠 정렬을 먼저 사전학습해 통합 멀티모달 특징을 만든 뒤 나머지 학습
- 생성한 멀티모달 특징이 기존 특징보다 낫다고 보고

### 이미지를 텍스트로 바꾸기 (상충하는 근거)
- Kieu 외 2025 (위): VLM이 제목을 참고해 만든 세밀한 설명이 도움
- **Frozen LVLMs for Micro-Video Recommendation (Sun 외, arXiv 2512.21863)** 【초록】: **중간 은닉 상태가 캡션 기반 표현보다 일관되게 낫다** (캡션이 세밀한 시각 정보를 버림). 층마다 효과가 크게 다름. ID 임베딩은 대체보다 **결합**이 낫다
- **시사점:** "이미지를 설명문으로 바꿔 텍스트에 넣기"는 직관적이지만 근거가 엇갈림. 53,232장 캡션 생성은 L4로 수 시간 → 이번에는 탐색 후보로만

## 6. 레버 ⑥ · ⑦: ID와 콜드스타트

### VBPR (He · McAuley, AAAI 2016) 【초록】
- 사전학습 CNN 특징 + 학습되는 시각 차원을 MF에 결합. BPR-MF 대비 전체 상품 +12% 이상, **콜드 상품(학습 피드백 5개 미만) +28% 이상**. 의류에서 휴대폰보다 시각 효과가 큼
- **우리 사후 결과(희소 · 신규 약 2배)는 10년 된 관찰과 같은 방향** → 새 발견이 아니라 최신 인코더 · 통제된 대조군에서의 **확인**으로 서술

### PixelRec (위), DropoutNet (위), Frozen LVLM (위)
- 공통: ID는 기존 상품에서 강하고, 이미지는 콜드 상품에서 강하다 → **ID와 이미지를 결합하되 ID 의존을 조절**하는 것이 실무적 답

---

## 7. 레버 ⑧: 학습 목표 — 베이스라인 격차의 원인

### Sampling-Bias-Corrected Neural Modeling for Large Corpus Item Recommendations (Google, RecSys 2019) 【2차, 저자 확인 필요】
- Two-Tower의 배치 내 부정 샘플은 인기 분포가 거듭제곱 법칙일 때 편향 → 상품 빈도를 추정해 **logQ 보정**. YouTube 검색 단계에 사용
- 후속: Correcting the LogQ Correction (arXiv 2507.09331, RecSys 2025) — 표준 유도의 문제를 지적하고 수정
- **우리와의 관계:** 실험기록의 추정 원인("배치 내 softmax가 인기 상품을 부정 샘플로 자주 뽑아 인기도를 억누름")과 정확히 같은 문제. logQ 보정은 몇 줄 수정으로 가능하고, **베이스라인 격차라는 가장 큰 약점**을 직접 겨냥

## 8. 우리 연구의 위치 (무엇이 새로운가)

| 선행 연구가 한 것 | 비어 있는 것 (우리 기여 후보) |
|---|---|
| ID 기반 그래프 모델에서 인코더 비교 (Ducho, Ye 외) — 차이 작음 | **ID 없는 콘텐츠 모델**에서 인코더 비교 — 차이 약 2배. **같은 구조 쌍**으로 사전학습 대 패션 적응 분리 |
| 모달리티 knockout (Ye 외) — 입력 크기 변화가 섞임 | **섞은 이미지 대조군**(전체 · 품목 안)으로 입력 크기 통제한 기여도 |
| 모달리티 불균형 처방 (CKD, SMD) — Amazon 데이터, 결측 강건성 중심 | 패션 실구매 데이터에서 **모달리티 드롭아웃이 이미지 기여와 전체 성능을 함께 올리는가** |
| 콜드스타트에서 이미지 효과 (VBPR, PixelRec) | 최신 인코더 6종 × 구매 기록 구간에서 같은 방향인지 확인 |
| 미세 조정이 중요 (MoRec, PixelRec) | (우리는 안 함 — 한계) |

**새 논문 축 (제안):** "텍스트 + 이미지 추천에서 이미지를 어떻게 써야 하는가 — 인코더 · 결합 · 적용 대상에 대한 통제 실험"
- RQ1 어떤 인코더: 사전학습이 패션 적응보다 중요 (기존 결과 + 재검증 + DINOv2)
- RQ2 어떻게 결합 · 학습: 모달리티 드롭아웃, 결합 구조, 정규화, logQ (신규)
- RQ3 어디에: 콜드 상품 (재검증, 확인으로 서술)
