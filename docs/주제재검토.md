> 앞선 문서: [계획변경정리.md](계획변경정리.md) (원래 계획과 지금까지의 변경) · 수치: [실험기록.md](실험기록.md)

## 한눈에 보기

- 앞서 제안한 주제 **"이미지 효과는 인코더가 결정한다"는 약하다.** 인코더에 따라 성능이 다르다는 건 이미 여러 연구가 보였고, 심사자가 "당연하다"고 볼 수 있다. 우리 비교도 구조가 다른 인코더끼리라 "패션 특화" 때문인지 구분이 안 된다.
- 핵심 선행 연구(Ye 외 2025)의 **원문을 직접 확인**했고, 이전에 공유한 내용 중 두 가지가 부정확했다 (1절).
- 원문을 보면 "이미지는 거의 기여하지 않는다"는 결론은 **특정 조건 세 가지**(범용 인코더, ID를 쓰는 모델, 기존 상품만 평가)에서 나왔다.
- 제안: 질문을 **"이미지는 어떤 조건에서 추천에 도움이 되는가"**로 넓힌다. 지금까지의 실험과 결과(1차 가설 불지지 포함)는 모두 그대로 쓰이고, **추가 실험 최대 73회(1시간 반 안팎)**만 더 하면 된다.
- 추가 실험은 **실행 전에 가설과 판정 기준을 먼저 등록**한다 (두 번째 사전 등록, 4절).

## 1. 이전 공유 내용 정정 (Ye 외 2025 원문 확인)

원문: Ye 외, *Are Multimodal Embeddings Truly Beneficial for Recommendation?* (arXiv 2508.07399v2, 18쪽). 이전에는 웹 요약을 근거로 설명했는데, 원문과 다른 부분이 있었다.

| 이전에 공유한 말 | 원문에서 확인한 사실 |
|---|---|
| "ResNet을 ViT로 바꿔도 결론이 바뀌지 않았다고 보고했다" | 본문에 ViT 관련 서술이 없다. 부록 **Table 12**에 "ViT 기반 시각 임베딩" 표가 있으나 본문에서 인용하지 않고, 어떤 ViT인지도 적혀 있지 않다. 이 표는 **전체 성능 변화**(대부분 ±5% 안팎)만 보여주며, 이미지 기여도가 달라지는지는 재지 않았다 |
| "Clothing에서도 이미지를 빼면 대부분 5% 미만 하락" | "대부분의 모델에서 영향이 작다"는 맞다. 그러나 **이미지에 민감한 모델**(GRCN, LGMRec, MMGCN)은 Clothing에서 이미지를 빼면 NDCG@10이 **11~14% 하락**했다 (6.1절). 우리 결과(+14%)와 크기가 비슷해 **모순이 아니다** |

앞으로 논문에 인용하는 문장은 원문에서만 가져온다.

### 원문이 실제로 한 것과 주장한 것
- 데이터: Amazon Baby · Sports · Clothing (MMRec 벤치마크)
- 특징: MMRec이 **미리 뽑아 둔 ResNet-50** 이미지 특징 + Sentence-BERT 텍스트
- 모델: 멀티모달 추천 모델 14개. **모두 상품 ID 임베딩을 함께 쓰는 모델**. 평가는 MMRec 분할 그대로 (학습에 등장한 상품)
- 방법: 이미지·텍스트 임베딩을 노이즈나 상수로 바꿨을 때 성능이 얼마나 떨어지는지 측정 (knockout)
- 결론 (원문 번역): "모델들은 텍스트 지배 상태로 작동한다. 텍스트 신호가 더 쉽게 학습되어 시각 신호를 덮어버리고, 시각 신호는 대부분 활용되지 않는다."
- 저자들이 든 원인: 텍스트가 배우기 쉬움, 이미지 임베딩 분포가 더 흩어져 있음

### 원문이 시험하지 않은 조건
1. **이미지 특징의 도메인:** 기여도 측정은 범용 ResNet-50 하나로만 했다
2. **ID 임베딩의 영향:** 모든 모델이 ID를 쓴다. 구매 기록이 충분한 상품은 ID가 대부분을 설명하므로 이미지가 할 일이 적다
3. **신규 상품:** 학습에 등장한 상품만 평가했다. 이미지가 가장 필요한 상황이 빠져 있다

## 2. 새 주제 제안

> **제목(안): 패션 추천에서 이미지는 언제 도움이 되는가 — 인코더, ID, 신규 상품의 조건 분석**

### 왜 이 질문인가
- Ye 외는 "이미지는 추천에 거의 기여하지 않는다(텍스트 지배)"고 결론 냈다.
- 같은 질문을 H&M 실구매 데이터로 잰 우리 결과에서는 이미지가 텍스트 위에 **+14%**(신규 상품 +46%)를 더했다.
- 두 결과는 데이터, 모델, 인코더, 평가 대상이 모두 다르다. 누가 틀렸다기보다 **조건이 달라서** 갈렸을 가능성이 크다. 조건을 하나씩 바꿔 이미지가 쓸모없는 조건과 쓸모 있는 조건을 밝힌다.
- (v2 정정) 이전 초안의 "업계에서는 이미지가 추천에 효과적"이라는 대비는 뺀다. Pinterest 자료는 **시각 검색**과 **유사 상품(Related Pins)** 실험이고, Mercari도 **유사 상품 추천**이다. 우리 주제인 **개인화 추천**의 근거로 쓰기 어렵다. 서론은 "선행 연구 결론 대 우리 관찰, 그리고 조건 차이"로 간다.

### "당연하지 않나"라는 비판에 대한 답
- 조건 하나하나(인코더 품질, ID 대 콘텐츠, 콜드스타트)는 각각 알려져 있다.
- 이 논문의 기여는 **셋을 한 실험에서 교차해**, "텍스트 지배" 결론이 성립하는 조건과 성립하지 않는 조건을 같은 데이터로 보여주는 것이다.
- 인코더 효과는 **출발점이 같은 범용 대 패션 적응 모델 쌍 두 개**로 확인한다 (한 쌍으로 일반화하지 않는다).
- 선행 연구를 "반박"한다고 쓰지 않는다. **"선행 연구가 다루지 않은 조건을 채운다"**로 쓴다.

### 처음 주제와의 관계
- 처음: "이미지는 **어떤 상품**에 도움이 되는가" → 상품 유형(패턴 대 무지) 하나만 봤고 **불지지**
- 새 주제: "이미지는 **어떤 조건**에서 도움이 되는가" → 상품 유형을 포함해 인코더, ID, 신규 상품까지
- 논문 흐름: "상품 유형이 조건일 거라 예상했지만 아니었다. 이어서 인코더와 ID를 사전 등록 후 검증했다"
- 주의: **결과를 본 뒤 넓힌 질문**이다. 그래서 추가 실험은 반드시 사전 등록 후 실행하고, 논문에 그 순서를 밝힌다.

### 추가 실험 2: ID 있는 Two-Tower
- 상품 타워 입력에 **학습되는 상품 ID 임베딩**을 이어 붙인다. 고객 타워는 그대로 (콘텐츠 임베딩 평균).
- 학습 기간에 한 번도 팔리지 않은 상품의 ID 임베딩은 **0**으로 둔다.
- 새 모델이므로 **튜닝 규칙**을 따로 정한다 (4-3절).
- (v3) 이 버전은 Ye 외 조건 중 **일부(상품 ID)만** 반영한다. Ye 외의 모델들은 고객과 상품 모두 ID를 쓰지만, 우리 모델은 **상품 쪽에만 ID**가 있고 고객 쪽은 콘텐츠 평균이다 (한계 절에 명시).
- (v3) 최종 학습 방식은 1차와 같다: 검증 주로 설정을 고른 뒤 **학습 + 검증 기간으로 다시 학습**해 테스트 주를 평가한다.

## 4. 두 번째 사전 등록 (v2 초안, 팀 검토 후 확정·커밋하고 나서 실행)

### 4-1. 측정값
- **이미지 내용 기여도(상대)** = [R(텍스트 + 이미지) − R(텍스트 + 전체 섞은 이미지)] ÷ R(텍스트 + 전체 섞은 이미지). R = 고객별 평균 Recall@300.
  - 입력 크기가 같은 두 조건의 차이라 "입력이 커져서 생긴 효과"가 섞이지 않는다.
  - (v2) 상대값을 주 측정값으로 쓴다. ID 있는 모델과 없는 모델은 기본 성능 수준이 다를 수 있어서, 절대 차이로 비교하면 기본 성능이 높은 쪽이 기여도도 커 보일 수 있다. **절대값도 함께 보고**한다.
- 통계: 고객 단위 짝지은 부트스트랩 1,000회. seed 3개는 seed별로 계산해 평균하고, 모든 seed가 같은 부트스트랩 추출을 공유한다.
- (v3) **구간별 계산 범위:** 어떤 구간(전체 / 기존 상품 등)의 기여도를 잴 때는 분자와 분모의 R을 **모두 그 구간의 구매로만** 계산한다. 그 구간 구매가 없는 고객은 해당 구간 평균에서 제외한다 (1차의 채점 규칙과 같음).

### 4-2. 확증 검정 (두 개)

| 가설 | 비교 | 판정 기준 |
|---|---|---|
| **H1 (도메인 적응)** | ID 없음, 전체 구매: **주 쌍** Marqo의 상대 기여도 − 범용 SigLIP B/16의 상대 기여도 | 차이의 **97.5% 구간** 하한 > 0이면 지지 |
| **H2 (ID가 이미지를 가림)** | Marqo, **기존 상품**(4-4절) 구매: ID 없음의 상대 기여도 − ID 있음의 상대 기여도 | 차이의 **97.5% 구간** 하한 > 0이면 지지 |

- (v2) 확증 검정이 두 개이므로 **본페로니 보정**으로 각각 97.5% 구간을 쓴다 (전체 오류율 5%).
- **재현 쌍**(FashionCLIP 2.0 − LAION CLIP B/32)은 별도 검정이 아니라 **방향 확인**으로 쓴다: 점추정의 부호가 H1과 같은지 보고하고 95% 구간을 함께 적는다.
- 나머지는 모두 **탐색적**으로 보고한다: 신규 상품 구간, 같은 품목 안 섞기 기준 기여도, OpenAI CLIP · ResNet 포함 비교, ID 있음 + 범용 인코더 조합이 Ye 외와 비슷한 양상을 보이는지, 기존 상품 기준값을 바꾼 민감도 분석.
- 어느 결과가 나와도 보고한다.
  - H1 불지지: "같은 구조에서는 패션 적응의 효과가 뚜렷하지 않다" → 효과는 구조(SigLIP) 쪽에서 왔을 가능성
  - H2 불지지: "ID를 써도 기존 상품에서 이미지 기여는 줄지 않는다"

### 4-3. ID 모델 튜닝 규칙 (v2 추가)
- 기존 학습 설정(h2: 학습률 0.0005, 8에폭 등)은 그대로 두고, **ID 관련 설정만** 아래 후보 중에서 고른다.

| 후보 | ID 임베딩 크기 | ID 드롭아웃 |
|---|---|---|
| i1 | 32 | 0 |
| i2 | 64 | 0 |
| i3 | 64 | 0.1 |
| i4 | 64 | 0.3 |

- 선택 기준: **ID 있는 Marqo, 텍스트 + 이미지 조건, seed 42의 검증 주 Recall@300** 1등. 고른 설정을 ID 있는 모든 조건에 똑같이 쓴다. 1차 튜닝과 같은 방식이다.
- ID 드롭아웃(학습 중 일정 확률로 ID 임베딩을 0으로 바꿈)을 후보에 넣은 이유: 테스트 때 신규 상품은 ID가 0인데, 학습 중에 0인 입력을 한 번도 보지 못하면 모델이 처음 보는 입력이 된다 (5번 리뷰). 드롭아웃이 선택되면 이 문제가 줄어든다.
- (v3) **드롭아웃이 H2에 주는 영향:** 드롭아웃은 모델이 ID 대신 콘텐츠를 쓰도록 유도해 ID 모델의 이미지 기여도를 키운다. 즉 i3·i4가 선택되면 **H2가 지지되기 더 어려워지는(보수적인) 방향**이다. 그래서
  - 선택된 설정을 결과에 명시한다.
  - 선택 결과와 관계없이 **드롭아웃 0 설정(i2)**으로도 ID 있는 조건을 seed 3개로 돌려 **탐색적 민감도 분석**으로 함께 보고한다. i2가 ID를 그대로 쓰는 조건에 더 가깝다.

### 4-4. "기존 상품" 정의 (v2 추가)
- 학습 기간(검증 주 포함, 즉 최종 학습에 쓰는 전체 기간)에 **10회 이상 팔린 상품**의 구매. ID 임베딩이 충분히 학습된 상품만 보기 위해서다.
- 1~9회 팔린 상품은 "희소 상품"으로 따로 탐색적 보고한다. 기준값 5와 20으로 바꾼 민감도 분석도 탐색적으로 보고한다.
- 신규 상품은 기존 정의 그대로 (전체 기록 기준 테스트 주에 처음 팔린 상품).

### 4-5. 해석 시 한계 (v2 추가)
- ID 있는 모델의 **신규 상품** 성능은 "학습 중에는 ID가 있다가 테스트에서만 0이 되는" 불일치 때문에 실제보다 낮게 나올 수 있다 (드롭아웃이 선택되지 않은 경우 특히). H2는 기존 상품만 보므로 영향이 없고, 신규 상품 비교에서는 이 한계를 적는다.

## 6. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 결과를 본 뒤 질문을 넓혔다는 비판 | 추가 실험은 사전 등록 후 실행, 논문에 순서를 밝힘. 1차 가설 불지지도 그대로 보고 |
| 한 쌍으로 일반화한다는 비판 | 출발점이 같은 쌍 두 개 (주 쌍 + 재현 쌍) |
| Ye 외와 모델(그래프 대 Two-Tower)·데이터(Amazon 대 H&M)가 다름 | "재현"이나 "반박"이 아니라 "조건이 결과를 바꾸는지"로 서술 |
| ID 유무에 따라 기본 성능이 달라 기여도 비교가 불공정 | 상대 기여도를 주 측정값으로, 절대값도 함께 보고 |
| ID 모델 설정에 결과가 좌우됨 | 튜닝 후보와 선택 규칙을 사전 등록 (4-3절) |
| "기존 상품" 정의가 자의적 | 기준(10회)을 사전 등록, 5·20회 민감도 분석 |
| 확증 검정 2개의 다중 비교 | 본페로니 보정 (97.5% 구간) |
| 신규 상품에서 ID 모델의 입력 불일치 | ID 드롭아웃을 튜닝 후보에 포함, 한계 명시 (4-5절) |
| 조건이 많아 3쪽에 안 들어감 | 확증 검정 2개 + 표 1개 + 그림 1개로 제한 |
| 단순 베이스라인에 짐 (재구매 + 인기 0.257 vs 모델 0.106) | ID 있는 모델에서 격차가 줄어드는지 함께 보고. 결합 후보 분석은 시간 여유가 있을 때 |
| Marqo · FashionCLIP 학습 데이터에 H&M 상품이 포함됐는지 알 수 없음 | 구매 정보가 새는 것은 아니지만 한계에 명시 |
| 이미지 임베딩 정규화 차이 (원문: "텍스트는 정규화, 이미지는 아님") | 우리는 둘 다 정규화함. 한계·향후 연구에 한 줄 |
| 우리 ID 모델은 상품 쪽에만 ID (Ye 외는 고객·상품 모두) | "Ye 외 조건의 일부를 반영"으로만 서술, 한계에 명시 |
| ID 드롭아웃 선택이 H2를 보수적으로 만듦 | 선택 설정 명시 + 드롭아웃 0(i2) 민감도 분석 병행 |
