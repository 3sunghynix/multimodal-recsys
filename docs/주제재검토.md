# 논문 주제 재검토: "이미지는 언제 추천에 도움이 되는가"

> 3성하이닉스 팀 공유용 · 2026-09-30 · 작성 김유환 · **팀 합의 전 제안서**
> 앞선 문서: [계획변경정리.md](계획변경정리.md) (원래 계획과 지금까지의 변경) · 수치: [실험기록.md](실험기록.md)

## 한눈에 보기

- 앞서 제안한 주제 **"이미지 효과는 인코더가 결정한다"는 약하다.** 인코더에 따라 성능이 다르다는 건 이미 여러 연구가 보였고, 심사자가 "당연하다"고 볼 수 있다. 우리 비교도 구조가 다른 인코더끼리라 "패션 특화" 때문인지 구분이 안 된다.
- 핵심 선행 연구(Ye 외 2025)의 **원문을 직접 확인**했고, 이전에 공유한 내용 중 두 가지가 부정확했다 (1절).
- 원문을 보면 "이미지는 거의 기여하지 않는다"는 결론은 **특정 조건 세 가지**(범용 인코더, ID를 쓰는 모델, 기존 상품만 평가)에서 나왔다.
- 제안: 질문을 **"이미지는 어떤 조건에서 추천에 도움이 되는가"**로 넓힌다. 지금까지의 실험과 결과(주 가설 불지지 포함)는 모두 그대로 쓰이고, **추가 실험 약 30회(30분 안팎)**만 더 하면 된다.
- 추가 실험은 **실행 전에 가설과 판정 기준을 먼저 등록**한다 (두 번째 사전 등록, 4절 초안).

## 1. 이전 공유 내용 정정 (Ye 외 2025 원문 확인)

원문: Ye 외, *Are Multimodal Embeddings Truly Beneficial for Recommendation?* (arXiv 2508.07399v2, 18쪽). 이전에는 웹 요약을 근거로 설명했는데, 원문과 다른 부분이 있었다.

| 이전에 공유한 말 | 원문에서 확인한 사실 |
|---|---|
| "ResNet을 ViT로 바꿔도 결론이 바뀌지 않았다고 보고했다" | 본문에 ViT 관련 서술이 없다. 부록 **Table 12**에 "ViT 기반 시각 임베딩" 표가 있으나 본문에서 인용하지 않고, 어떤 ViT인지도 적혀 있지 않다. 이 표는 **전체 성능 변화**(대부분 ±5% 안팎)만 보여주며, 이미지 기여도가 달라지는지는 재지 않았다 |
| "Clothing에서도 이미지를 빼면 대부분 5% 미만 하락" | "대부분의 모델에서 영향이 작다"는 맞다. 그러나 **이미지에 민감한 모델**(GRCN, LGMRec, MMGCN)은 Clothing에서 이미지를 빼면 NDCG@10이 **11~14% 하락**했다 (6.1절). 우리 결과(+14%)와 크기가 비슷해 **모순이 아니다** |

앞으로 논문에 인용하는 문장은 원문에서만 가져온다.

### 원문이 실제로 한 것과 주장한 것
- 데이터: Amazon Baby · Sports · Clothing (MMRec 벤치마크)
- 특징: MMRec이 **미리 뽑아 둔 ResNet-50** 이미지 특징 + Sentence-BERT 텍스트
- 모델: 멀티모달 추천 모델 14개. **모두 상품 ID 임베딩을 함께 쓰는 모델**. 평가는 MMRec 분할 그대로 (학습에 등장한 상품)
- 방법: 이미지·텍스트 임베딩을 노이즈나 상수로 바꿨을 때 성능이 얼마나 떨어지는지 측정 (knockout)
- 결론 (원문 번역): "모델들은 텍스트 지배 상태로 작동한다. 텍스트 신호가 더 쉽게 학습되어 시각 신호를 덮어버리고, 시각 신호는 대부분 활용되지 않는다."
- 저자들이 든 원인: 텍스트가 배우기 쉬움, 이미지 임베딩 분포가 더 흩어져 있음

### 원문이 시험하지 않은 조건
1. **이미지 특징의 도메인:** 기여도 측정은 범용 ResNet-50 하나로만 했다
2. **ID 임베딩의 영향:** 모든 모델이 ID를 쓴다. 구매 기록이 충분한 상품은 ID가 대부분을 설명하므로 이미지가 할 일이 적다
3. **신규 상품:** 학습에 등장한 상품만 평가했다. 이미지가 가장 필요한 상황이 빠져 있다

## 2. 새 주제 제안

> **제목(안): 패션 추천에서 이미지는 언제 도움이 되는가 — 인코더, ID, 신규 상품의 조건 분석**

### 왜 이 질문인가
- 학계(Ye 외): 이미지는 거의 기여하지 않는다 (텍스트 지배)
- 업계(Pinterest, Mercari 등 실서비스 실험)와 우리 결과: 이미지를 넣으면 성능이 확실히 오른다
- 둘 다 실험 결과라면, 누가 틀렸다기보다 **실험 조건이 달라서** 갈렸을 가능성이 크다. 조건을 하나씩 바꿔 이미지가 쓸모없는 조건과 쓸모 있는 조건을 밝힌다.

### "당연하지 않나"라는 비판에 대한 답
- 조건 하나하나(인코더 품질, ID 대 콘텐츠, 콜드스타트)는 각각 알려져 있다.
- 이 논문의 기여는 **셋을 한 실험에서 교차해**, 학계의 "텍스트 지배" 결론이 성립하는 조건과 성립하지 않는 조건을 같은 데이터로 보여주는 것이다.
- 선행 연구를 "반박"한다고 쓰지 않는다. **"선행 연구가 다루지 않은 조건을 채운다"**로 쓴다.

### 처음 주제와의 관계
- 처음: "이미지는 **어떤 상품**에 도움이 되는가" → 상품 유형(패턴 대 무지) 하나만 봤고 **불지지**
- 새 주제: "이미지는 **어떤 조건**에서 도움이 되는가" → 상품 유형을 포함해 인코더, ID, 신규 상품까지
- 논문 흐름: "상품 유형이 조건일 거라 예상했지만 아니었고, 조건은 인코더와 ID였다(추가 실험 결과에 따라)"
- 주의: **결과를 본 뒤 넓힌 질문**이다. 그래서 추가 실험은 반드시 사전 등록 후 실행하고, 논문에 그 순서를 밝힌다.

## 3. 지금 가진 것과 더 필요한 것

| 조건 | 상태 | 지금까지 결과 |
|---|---|---|
| 상품 유형 (패턴 대 무지) | 완료 (사전 등록) | **불지지**: +0.0018 [−0.0009, +0.0051] |
| 인코더 3종 (ResNet-50, CLIP B/32, Marqo) | 완료 (탐색적) | 이미지 추가 효과 +0.0048 / +0.0076 / +0.0128 |
| 기존 상품 대 신규 상품 | 완료 (탐색적) | Marqo: 전체 +0.0128, 신규 상품 +0.0234 |
| 섞은 이미지 대조군 | 완료 | 모델이 이미지 내용을 실제로 씀, 세밀한 시각 정보에서 옴 |
| **구조가 같은 범용 대 패션 인코더** | **추가 필요** | — |
| **ID 있음 대 없음** | **추가 필요** | — |

### 추가 실험 1: 구조가 같은 인코더 쌍
- Marqo-FashionSigLIP은 범용 **SigLIP ViT-B/16 (WebLI)**에서 패션 데이터로 추가 학습한 모델이다 (Marqo 공개 자료).
- 원본 범용 SigLIP ViT-B/16을 같은 조건으로 돌리면 **구조는 같고 패션 학습만 다른** 비교가 된다.
- 현재 비교(Marqo 대 CLIP B/32)는 구조, 해상도, 학습 데이터가 모두 달라 "패션 특화" 효과를 분리할 수 없다.

### 추가 실험 2: ID 있는 Two-Tower
- 상품 타워 입력에 **학습되는 상품 ID 임베딩**을 추가한다. 고객 타워는 그대로 (콘텐츠 임베딩 평균).
- 학습 기간에 한 번도 팔리지 않은 상품(신규 상품)의 ID 임베딩은 **0으로 둔다** (실제 서비스에서 처음 보는 상품과 같은 상태).
- 이 버전이 Ye 외의 조건(ID 사용)에 가깝다.

### 실행할 조건 (seed 42 · 43 · 44)

| ID | 인코더 | 텍스트만 | 텍스트 + 이미지 | + 전체 섞기 | + 같은 품목 안 섞기 |
|---|---|---|---|---|---|
| 없음 | Marqo | 기존 | 기존 | 기존 | 기존 |
| 없음 | 범용 SigLIP | 기존 (텍스트만은 공통) | **추가** | **추가** | **추가** |
| 있음 | Marqo | **추가** | **추가** | **추가** | **추가** |
| 있음 | 범용 SigLIP | (위와 공통) | **추가** | **추가** | **추가** |

- 추가 조건 10개 × seed 3개 = **30회**. 1회 약 20초라 학습 자체는 10분 정도이고, 불러오기와 분석을 포함해 30분 안팎이다.
- 임베딩 추출 1회 (범용 SigLIP, 상품 53,232개, L4에서 몇 분)
- 평가 구간에 **기존 상품**(신규 상품이 아닌 구매)을 추가한다.

## 4. 두 번째 사전 등록 (초안, 팀 검토 후 확정·커밋하고 나서 실행)

**측정값:** 이미지 내용 기여도 = Recall@300(텍스트 + 이미지) − Recall@300(텍스트 + 전체 섞은 이미지).
입력 크기가 같은 두 조건의 차이라 "입력이 커져서 생긴 효과"가 섞이지 않는다. 고객 단위 짝지은 부트스트랩 1,000회, seed 3개 평균, 95% 구간.

| 가설 | 비교 | 판정 기준 |
|---|---|---|
| **H1 (도메인 적응)** | ID 없음, 전체 구매: Marqo의 이미지 기여도 − 범용 SigLIP의 이미지 기여도 | 차이의 95% 구간 하한 > 0이면 지지 |
| **H2 (ID가 이미지를 가림)** | Marqo, **기존 상품** 구매: ID 없음의 이미지 기여도 − ID 있음의 이미지 기여도 | 차이의 95% 구간 하한 > 0이면 지지 |

- 확증 검정은 이 두 개뿐이다. 나머지(신규 상품에서의 차이, ResNet · CLIP 포함 비교, ID 있음 + 범용 인코더 조합이 Ye 외 결과를 재현하는지 등)는 모두 **탐색적**으로 보고한다.
- 어느 결과가 나와도 보고한다.
  - H1이 불지지면 "같은 구조에서는 패션 학습의 효과가 뚜렷하지 않다", 즉 효과가 구조(SigLIP) 쪽에서 왔을 가능성
  - H2가 불지지면 "ID를 써도 이미지 기여는 줄지 않는다"

## 6. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 결과를 본 뒤 질문을 넓혔다는 비판 | 추가 실험은 사전 등록 후 실행, 논문에 순서를 밝힘. 1차 가설 불지지도 그대로 보고 |
| Ye 외와 모델(그래프 대 Two-Tower)·데이터(Amazon 대 H&M)가 다름 | "재현"이나 "반박"이 아니라 "조건이 결과를 바꾸는지"로 서술 |
| 조건이 많아 3쪽에 안 들어감 | 확증 검정 2개 + 표 1개 + 그림 1개로 제한 |
| 신규 상품의 ID 처리 방식에 결과가 좌우됨 | "0으로 둔다"를 사전 등록에 명시 |

| Marqo 학습 데이터에 H&M 상품이 포함됐는지 알 수 없음 | 구매 정보가 새는 것은 아니지만 한계에 명시 |
| 이미지 임베딩 정규화 문제 (원문에 "텍스트는 정규화, 이미지는 아님" 언급) | 우리는 둘 다 정규화함. Ye 외 결과와의 차이 원인 중 하나일 수 있어 한계·향후 연구에 한 줄 |
