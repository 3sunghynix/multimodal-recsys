# 추천 개선 계획

> 작성: 김유환 / 2026-11-03 / 상태: 팀 검토용
> 현재 모델: [추천모델설계.md](추천모델설계.md), 결과: [오프라인결과.md](오프라인결과.md), 시뮬레이터: [페르소나_v0.3.md](페르소나_v0.3.md)
> **원칙:** 모든 개선은 지금 평가 방식 그대로 — valid로 고르고 test는 정한 설정만 한 번, 고객 단위 부트스트랩 95% 구간 — 검증한 뒤에만 채택한다. 온라인 효과는 시뮬레이터 A/B로 페르소나별 확인.

## 1. 지금 시스템의 약점

| # | 약점 | 영향 |
|---|---|---|
| W1 | 고객 이력을 단순 평균 — 최근에 산 것과 오래전 산 것을 같게 봄 | 순서 · 최근성 손실 (H&M은 최근 인기 7일이 전체 기간보다 MAP 2.4배) |
| W2 | 인기 가중치 γ · 브랜드 가산 β가 모든 고객에게 고정 | 고객 · 상황별 최적값을 못 씀 |
| W3 | 2단계(재정렬)가 규칙뿐, 학습형 랭커 없음 | API 명세의 `score` · `ranking_ms`가 비어 있음 (#32) |
| W4 | 인기를 섞으며 다양성 감소 | 커버리지 UME 단독 0.68 ~ 0.95 → 0.04 ~ 0.31 |
| W5 | 재구매 · 색상 변형을 따로 다루지 않음 | H&M 재구매 신호 미활용, 같은 옷 색상만 다른 상품이 목록에 반복 |
| W6 | 탐색 없음 | 명세 `is_exploration` 전부 false, 신규 상품 노출 기회 부족 |
| W7 | 부정 신호(1 ~ 2점 리뷰) 미사용 | 싫어한 상품 정보 손실 |
| W8 | 비교 모델이 인기 · UME 2개 | 과제 "3 ~ 4개 모델 비교" 요구에 부족 |

## 2. 우리 논문에서 가져올 것

| 논문 결과 | 서비스 적용 |
|---|---|
| UME(따로 학습 + 점수 합)가 함께 학습보다 좋음 (+39%) | 적용 완료 |
| 인기 + UME 혼합이 인기 단독보다 좋음 (B2 + UME) | 적용 완료 (인기 점수 γ) |
| UME 효과는 기존 상품에 집중, **신규 상품은 함께 학습 모델이 더 좋음** | 신규 · 희소 상품 구간에 한해 함께 학습 모델 점수를 섞는 실험 |
| 신규 상품 전용 칸은 정확도와 맞바꿈 (H19) | 탐색 칸(P5)으로 작게, 시뮬레이터 A/B로 재확인 |
| 인코더 사전학습 규모가 중요 (H7), 패션 특화 미세조정은 효과 없음 (H1) | 미세조정보다 더 큰 사전학습 이미지 인코더 교체 실험 |
| 이미지 드롭아웃은 다른 주에서 재현 실패 | 적용하지 않음 |

## 3. 개선 후보

### P1. 재구매 · 색상 변형 후보 + 묶기 — 작업 작음, H&M 효과 큼 (W5)
- 후보 생성을 여러 경로로: UME 후보 + **재구매 후보**(고객이 전에 산 상품) + **같은 상품 코드의 다른 색상** → 합친 뒤 재정렬. 후보 생성 · 순위를 나누는 2단계 구조(Covington et al., 2016).
- H&M Kaggle 대회 상위 해법들의 공통 요소가 재구매 · 최근 인기 후보였다는 점이 근거.
- 화면에서는 같은 상품 코드를 하나로 묶는다.
- 측정: H&M MAP@12 · Recall@12, 재구매 비율, 목록 내 색상 변형 중복 수.

### P2. 최근성 반영 고객 벡터 (W1)
- 1단계 (작음): 평균 → 시간 감쇠 가중 평균 (최근일수록 큰 가중치). 서빙 · 학습 코드 몇 줄.
- 2단계 (중간): 순서 모델 고객 타워 — SASRec (Kang & McAuley, 2018), BERT4Rec (Sun et al., 2019).
- 세션 안 반응: GRU4Rec (Hidasi et al., 2016). 시뮬레이터의 여러 세션으로 측정 가능.

### P3. 학습형 랭커 = 2단계 재정렬 — 중간, 명세 대응에 필요 (W2 · W3)
- 후보 300개에 특성을 붙여 순위 학습: UME 텍스트 점수 · 이미지 점수, 인기, 최근성, 재구매 여부, 가격 적합도, 브랜드 친화도.
- LightGBM LambdaMART (Burges, 2010)로 시작, 시간이 되면 DeepFM (Guo et al., 2017) · DCN-V2 (Wang et al., 2021)와 비교.
- 효과: γ · β를 사람이 정하지 않고 학습 (고객별 텍스트 · 이미지 비중 포함), 명세 `score` · `pipeline_latency.ranking_ms` 실제 값, 설계 문서 3단계 중 2단계 완성.

### P4. 다양성 · 비율 맞춤 재정렬 — 작업 작음 (W4)
- MMR (Carbonell & Goldstein, 1998): 이미 고른 상품과 비슷한 상품(이미지 임베딩)은 점수를 깎는다.
- Calibrated Recommendations (Steck, 2018): 추천 목록의 카테고리 · 브랜드 비율을 고객 이력 비율에 맞춘다 → 브랜드 충성도를 "가산"보다 자연스럽게, 커버리지 일부 회복.
- 측정: MAP@12와 함께 커버리지 · 목록 내 다양성 · 브랜드 일치도의 교환 관계.

### P5. 탐색 · 밴딧 — 중간 (W6)
- 추천 12개 중 1 ~ 2칸을 신규 · 희소 상품 탐색용으로 — Thompson sampling, LinUCB (Li et al., 2010).
- 명세 `is_exploration` 대응, 논문 H19(신규 상품 칸 = 정확도와 맞바꿈)의 온라인 재확인.

### P6. 학습 개선 — 재학습 필요 (W7)
- 인기 편향 보정: 배치 안 부정 예시가 인기 상품을 과하게 벌주는 문제를 보정 (Yi et al., 2019, sampling-bias correction). 인기 점수 γ와 함께 효과 확인.
- 부정 신호: 1 ~ 2점 리뷰를 싫어한 상품으로 손실에 반영.
- 더 큰 사전학습 이미지 인코더로 교체 실험 (2장 H7).

### P7. 비교 모델 추가 (W8)
- ItemKNN (간단), LightGCN (He et al., 2020, ID 기반 그래프), SASRec (P2와 겸용).
- ID 기반 모델 vs 콘텐츠 기반 UME의 신규 상품 차이를 보여 줄 수 있음 → 관리자 모델 실험실 3 ~ 4개 비교.

## 4. 순서

| 순서 | 작업 | 이유 | 담당 |
|---|---|---|---|
| 1 | P1 재구매 · 색상 변형 후보 + 묶기, P2-1단계 최근성 가중 평균 | 작업 작고 H&M 효과 큼 | 김유환 |
| 2 | P3 LightGBM 랭커 | 명세 `score` · 파이프라인 단계, γ · β 학습 | 김유환 (API 연결 김형우) |
| 3 | P7 비교 모델 1 ~ 2개 (ItemKNN, SASRec) | 3 ~ 4개 모델 비교 요구 | 김유환 |
| 4 | P4 MMR · 비율 맞춤 재정렬 | 다양성 · 브랜드 지표 | 김유환 |
| 5 | P5 탐색 칸 | `is_exploration`, 시뮬레이터 A/B | 김유환 · 김광석 |
| 이후 | P6 학습 개선 | 재학습 필요, 실험으로 효과 확인 | 김유환 |

각 단계 결과는 [오프라인결과.md](오프라인결과.md)에 기존 표와 같은 형식으로 추가하고, 채택된 설정만 서빙에 반영한다.
