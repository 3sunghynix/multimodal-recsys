## 1. 논문의 한 줄 주장 (결과에 따라 고른다)

**H1 · H2 결과가 나온 뒤 아래 중 해당하는 것을 쓴다. 결과를 보고 가설이나 측정값을 바꾸지 않는다.**

| H1 (도메인 적응) | H2 (ID가 이미지를 가림) | 한 줄 주장 |
|---|---|---|
| 지지 | 지지 | 이미지의 기여는 인코더의 도메인 적응과 ID 사용 여부에 따라 달라진다. "텍스트 지배"는 범용 인코더와 ID가 겹친 조건에서 나타나는 현상일 수 있다 |
| 지지 | 불지지 | 패션 도메인 적응 인코더는 이미지 기여를 키우며, 이 효과는 ID를 추가해도 유지된다 |
| 불지지 | 지지 | 같은 구조에서 패션 적응의 효과는 뚜렷하지 않았다. 이미지 기여를 줄이는 조건은 ID 사용이었다 |
| 불지지 | 불지지 | 이미지는 텍스트 위에 일관되게 기여했으나, 그 크기를 설명하는 조건으로 도메인 적응과 ID는 확인되지 않았다 |

어느 경우든 **1차 사전 등록(패턴 대 무지) 불지지**와 **이미지가 텍스트 위에 기여한다는 탐색적 결과**는 함께 보고한다.

## 3. 절별 작성 가이드

### 3-1. 서론
**흐름**
1. 멀티모달 추천에서 이미지 · 텍스트 임베딩을 함께 쓰는 것이 일반화됐다.
2. 최근 Ye 외(2025)는 14개 모델을 분석해 "텍스트 지배" 결론을 냈다. 모델들이 이미지 신호를 대부분 활용하지 못한다는 것이다.
3. 그런데 그 분석은 특정 조건에서 이뤄졌다: 범용 ResNet-50 특징, ID를 쓰는 모델, 학습에 등장한 상품만 평가.
4. 우리 H&M 실구매 실험에서는 이미지가 텍스트 위에 +14%(신규 상품 +46%) 기여했다 (탐색적).
5. 질문: **이미지의 기여는 어떤 조건에서 나타나는가?**
6. 기여 (3개 이내, 결과에 맞게):
   - 출발점이 같은 범용 대 패션 적응 인코더 **두 쌍**으로 도메인 적응의 효과를 분리 (H1)
   - 상품 ID 유무에 따른 이미지 기여 비교 (H2)
   - 두 단계 사전 등록과 섞은 이미지 대조군으로 "모델이 이미지 내용을 실제로 쓰는지"까지 확인

**쓰지 말 것:** "업계에서는 이미지가 추천에 효과적이다" (근거 자료가 유사 상품 · 시각 검색 실험이라 개인화 추천 근거가 아님)

### 3-2. 관련 연구

### 3-3. 방법
- **모델:** Two-Tower. 상품 타워 입력 = 텍스트 임베딩 ⊕ 이미지 임베딩 (⊕ 상품 ID 임베딩). 고객 타워 입력 = 구매 상품 콘텐츠 임베딩의 평균. 배치 내 부정 샘플 softmax. 주 단위 학습 표본(그 주 이전 구매로 이력, 그 주 구매가 정답)이라 미래 정보 누수 없음.
- **ID 모델:** 학습 데이터에 없는 상품의 ID는 0. ID 드롭아웃(학습 중 확률 p로 ID 부분을 0으로).
- **섞은 이미지 대조군:** 상품마다 다른 상품의 이미지 임베딩을 배정. 전체 섞기 / 같은 품목(product_type) 안 섞기. 입력 크기가 같아 "입력이 커진 효과"를 통제.
- **측정값:** 상대 기여도 = [R(텍스트 + 이미지) − R(텍스트 + 섞은 이미지)] ÷ R(텍스트 + 섞은 이미지). R = 고객별 평균 Recall@300. 절대값 병기.
- **두 단계 사전 등록:** 1차(패턴 대 무지, 결과 확인 전 등록) → 불지지 → 질문을 넓혀 2차 등록(H1 · H2, 결과 확인 전 등록). **이 순서를 숨기지 말고 명시한다.**

## 5. 강조할 내용

1. **조건을 교차한 설계:** 인코더 도메인 × ID 유무 × 상품 신규성을 한 실험에서 비교. 선행 연구가 다루지 않은 조건을 채운다.
2. **출발점이 같은 인코더 쌍 두 개:** 구조를 고정하고 패션 적응만 다르게 해 "더 좋은 인코더라서"라는 해석을 배제한다. 한 쌍으로 일반화하지 않는다.
3. **섞은 이미지 대조군:** 입력 크기를 맞춘 대조로 "모델이 이미지 내용을 실제로 쓰는가"를 직접 확인한다. Ye 외도 지적한 "단순 결합 모델은 의미 없는 입력으로도 성능이 나온다"는 문제를 피한다.
4. **두 단계 사전 등록과 정직한 보고:** 1차 가설 불지지를 숨기지 않고, 질문을 넓힌 과정과 순서를 밝힌다. 사후 분석은 모두 탐색적으로 표시한다.
5. **실구매 · 시간 기준 평가와 신규 상품:** 미래 정보 누수 없는 시간 분할, 학습에 없던 신규 상품까지 평가한다.

| "유의하다"만 쓰기 | 추정값과 구간을 함께: "+0.0XX (97.5% 구간 [a, b])" |
| 탐색적 결과를 확증처럼 | 탐색적 결과는 "탐색적으로"라고 명시하고 결론의 근거로 쓰지 않는다 |
| 인과 단정 ("도메인 적응이 원인이다") | "같은 구조에서 도메인 적응 여부만 다른 두 쌍에서 …이 관찰됐다" |

### 6-2. 결과 해석
- **ID 모델이 약하다:** ID 있는 모델의 검증 점수가 ID 없는 모델보다 약 20% 낮았다 (과적합으로 판단). H2 결과는 "강한 ID 모델이 아닌 조건"에서 나온 것이다. 불지지면 "ID가 이미지를 가리지 않는다"가 아니라 "이 설정의 ID는 이미지를 가릴 만큼 강하지 않았다"로 쓴다.
- **ID 드롭아웃이 H2를 보수적으로 만든다:** 선택 설정 i4(드롭아웃 0.3)는 ID 모델이 콘텐츠를 더 쓰게 하므로 H2 지지를 어렵게 하는 방향이다. 드롭아웃 0(i2) 민감도 결과를 함께 적는다.
- **단순 베이스라인에 크게 진다:** 우리 모델은 재구매 + 인기(0.257)보다 낮다 (0.106). 논문의 주장은 최고 성능이 아니라 조건별 이미지 기여도임을 분명히 하고, 신규 상품에서는 인기 기반 방법이 0이라는 점을 함께 적는다.
- **상대 기여도의 분모:** 분모(섞은 이미지 조건의 R)가 작은 구간(신규 상품 등)은 상대값이 커 보일 수 있다. 절대값을 함께 보고한다.

### 6-3. 인용
- **원문을 직접 확인한 것만 인용한다.** 웹 요약을 근거로 쓰지 않는다 (이전에 이 문제로 두 번 정정함).
- 인용 확인 현황 (7절)을 보고 "확인 필요" 항목은 원문 확인 후 쓴다.

### 6-4. 한계 (결론 절에 쓸 후보, 중요한 순서)
1. 단일 데이터셋(H&M)과 Two-Tower 한 가지 모델. Ye 외와 모델(그래프 기반) · 데이터(Amazon)가 다름
2. ID 모델이 상품 쪽에만 ID를 쓰고, 과적합으로 ID 없는 모델보다 약함
3. 단순 베이스라인보다 낮은 절대 성능
4. 패션 적응 인코더(Marqo, FashionCLIP)의 학습 데이터에 H&M 상품이 포함됐는지 알 수 없음 (구매 정보 누수는 아님)
5. 임베딩 고정 (끝까지 학습시키지 않음), 이미지 · 텍스트 정규화 방식이 Ye 외와 다름
6. 두 번째 가설은 첫 번째 결과를 본 뒤 등록함 (사전 등록으로 실행 순서는 통제했으나, 질문 선택 자체는 결과의 영향을 받음)
