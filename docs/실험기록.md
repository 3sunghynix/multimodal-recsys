> 자동 기록(드라이브 `msrs_paper/`)을 사람이 읽기 좋게 요약한 문서. 결정과 그 이유, 계획에서 벗어난 점을 남긴다.
> 원본 수치: 드라이브 `results/`, 실행별 기록: `outputs/**/run_info.json`, 실행 로그: `logs/`.

- Marqo, 재구매 아닌 구매, 세밀 기여도, 상품군 가중 (패턴 − 무지) = +0.0018, 95% 구간 [−0.0009, +0.0051] → H1·H2 지지 안 됨
- 상품군별 결과도 분할 간 부호가 뒤바뀜 (원피스·전신: main −0.010, alt +0.015)

**탐색적 결과 (seed 3개 평균, 실험 A)**
- 이미지 추가 효과: 텍스트만 0.0928 → +Marqo 0.1056 (+14%). seed 표준편차 약 0.003
- 섞은 이미지(0.089~0.090)는 텍스트만보다도 낮음 → 모델이 이미지 내용을 실제로 씀
- 같은 품목 안 섞기 ≈ 전체 섞기 → 이미지 효과는 카테고리보다 세밀한 시각 정보에서 옴
- 신규 상품: 0.0513 → 0.0746 (+46%)
- 이미지만: Marqo 0.1034 > 텍스트만 0.0928 > CLIP 0.0789 > ResNet 0.0721
- `product_code` 수준에서도 이미지 효과 유지 (0.117 → 0.148): 색상 구분 효과로 부풀려진 것 아님
- alt 분할에서 재현 (0.0852 → 0.1018)

**문제: 단순 베이스라인에 크게 짐**
- 재구매 + 인기 0.257, 직전 1주 인기 0.230 vs Two-Tower(텍스트 + Marqo) 0.106. 파일럿 기준 3("비교할 만한 수준") 미통과
- 신규 상품 구간에서는 베이스라인 0, 콘텐츠 모델만 맞힘
