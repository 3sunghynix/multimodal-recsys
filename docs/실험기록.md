- 주의: ID 있는 조건의 신규 상품 상대값(특히 i2의 1.90)은 신규 상품 ID 0 입력의 학습·테스트 불일치로 대조군 성능(분모)이 떨어져 과장됨. 절대값은 다른 조건과 비슷(0.027~0.030)
