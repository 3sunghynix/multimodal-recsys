## 진행 기록

### 2026-09-28 · 01 데이터 준비 (김유환, Colab L4)
- H&M 원본 30.8GB → 구매 31,788,324건 (2018-09-20 ~ 2020-09-22)
- 상품 53,232개 (두 분할 기간 판매 + 이미지 보유). 계획서의 "약 2만 개"보다 많음: 임의로 자르지 않고 전부 사용
- main 분할: 고객 450,766명, 학습 7,279,270건, 테스트 2020-09-16 ~ 09-22, 테스트 고객 46,054명 · 구매 150,415건, 재구매 4.7%, 신규 상품 4.1%
- alt 분할: 테스트 2020-09-09 ~ 09-15, 테스트 고객 48,557명 · 구매 161,421건
- 사전 등록(`analysis_plan.yaml`) 확정: 실제 값 30종/19종 대조, 누락 없음. `Contrast`, `Application/3D`는 무지 원단에 장식이 붙은 경우가 많아 패턴이 아닌 질감·장식 그룹으로 확정 (결과 보기 전)
- 최근접 이웃 확인: Marqo는 패턴(체크, 그라데이션)과 옷 종류를 함께 구분, ResNet-50은 색·실루엣 위주. 같은 `product_code`의 색상 변형이 이웃으로 잡히는 것 확인

### 2026-09-29 · 02 튜닝 (김유환)
- C2, seed 42, 검증 주 Recall@300: h2 0.1065 (lr 0.0005, 8에폭) > h1 0.1053 > h3 0.1051 → h2 채택
- 후보 간 차이 약 0.001: 하이퍼파라미터에 민감하지 않음. 1회 학습 약 20초

### 2026-09-29 · 03 본 실험 A·B·C + 베이스라인 (김유환이 한 GPU로 전부 실행)
- 원래 세 명이 나눠 돌리기로 했으나 1회 20초라 한 사람이 전부 실행. 모든 비교가 같은 GPU에서 이뤄짐

**주 검정 (사전 등록) — 가설 불지지**
- Marqo, 재구매 아닌 구매, 세밀 기여도, 상품군 가중 (패턴 − 무지) = +0.0018, 95% 구간 [−0.0009, +0.0051] → H1·H2 지지 안 됨
- 상품군별 결과도 분할 간 부호가 뒤바뀜 (원피스·전신: main −0.010, alt +0.015)

**탐색적 결과 (seed 3개 평균, 실험 A)**
- 이미지 추가 효과: 텍스트만 0.0928 → +Marqo 0.1056 (+14%). seed 표준편차 약 0.003
- 섞은 이미지(0.089~0.090)는 텍스트만보다도 낮음 → 모델이 이미지 내용을 실제로 씀
- 같은 품목 안 섞기 ≈ 전체 섞기 → 이미지 효과는 카테고리보다 세밀한 시각 정보에서 옴
- 신규 상품: 0.0513 → 0.0746 (+46%)
- 이미지만: Marqo 0.1034 > 텍스트만 0.0928 > CLIP 0.0789 > ResNet 0.0721
- `product_code` 수준에서도 이미지 효과 유지 (0.117 → 0.148): 색상 구분 효과로 부풀려진 것 아님
- alt 분할에서 재현 (0.0852 → 0.1018)

**문제: 단순 베이스라인에 크게 짐**
- 재구매 + 인기 0.257, 직전 1주 인기 0.230 vs Two-Tower(텍스트 + Marqo) 0.106. 파일럿 기준 3("비교할 만한 수준") 미통과
- 신규 상품 구간에서는 베이스라인 0, 콘텐츠 모델만 맞힘

### 2026-09-29 · 추가 실험 결정 (결과 확인 후 추가 — 사전 등록 아님)
1. **D 묶음 (인기도 입력):** 상품 타워에 직전 1주·4주 판매량(log1p, z-점수)을 추가한 P0·P2·P3·P4 × seed 42·43·44. 라벨 주마다 그 주 이전 판매량으로 계산해 누수 없음. 목적: 베이스라인에 가까운 모델 위에서도 이미지 효과가 남는지 확인
2. **B·C 묶음 seed 43·44 추가:** 인코더 비교를 seed 3개로
3. 확인: 코드 수정 전후로 같은 데이터에서 기존 조건의 추천 결과가 완전히 같음 → 기존 seed 42 결과와 새 결과를 합쳐도 됨
4. 분석 보강: 기여도 자체의 부트스트랩 구간(`overall_contributions.csv`), 인코더별 그림(`fig2.png`)
