## 0. 한 쪽 요약

1. **이 문제에는 이름이 있다.** 멀티모달 학습 분야는 이를 **모달리티 불균형(modality imbalance)** · **모달리티 경쟁(competition)** · **모달리티 게으름(laziness)** · **탐욕적 학습(greedy learning)** 이라고 부른다. 한 모달리티가 학습을 먼저 장악하면 다른 모달리티는 덜 학습되고, 결과적으로 **멀티모달 모델이 가장 강한 단일 모달 모델을 거의 못 넘거나 오히려 진다** (Wang 외 CVPR 2020 등).
2. **우리 데이터에도 같은 신호가 있다.** Marqo 기준 이미지만 0.1034 > 텍스트만 0.0928인데, 둘을 합친 모델은 0.1056 (이미지만 대비 +2%). 단, **어느 쪽이 우세한지는 인코더에 따라 뒤집힌다** (ResNet은 이미지만 0.0745 < 텍스트만).
3. **처방은 네 계열이다** (BalanceBenchmark 2025 분류). 데이터 · 순전파(구조) · 목표 함수 · 최적화. 추천 분야에서는 **단일 모달 교사 증류(CKD, ACM MM 2024)** 가 대표적이고, 같은 논문에서 OGM · Gradient Blending도 비교 대상으로 쓰였다.
4. **주의할 점:** 대규모 벤치마크에서 **어느 방법도 모든 데이터에서 기준을 이기지는 못했고**, "완전한 균형"보다 "적당한 균형"이 더 나았다 (BalanceBenchmark). 정보량이 큰 모달리티를 억지로 낮추면 오히려 손해다.
5. **우리 결과의 재해석:** 이미지 드롭아웃이 효과가 있었던 것은 **우세한 모달리티(Marqo에서는 이미지)를 억제**하는 OGM 계열 논리와 같은 방향이다. 텍스트 드롭아웃이 불안정했던 것도 이와 맞는다 (약한 쪽을 더 약하게 만듦). 단, 이 해석은 **사후적**이라 검증이 필요하다.
6. **다음 실험 후보 (5절):** ① 이미지 활용도 진단 지표(추천 때 이미지를 평균으로 바꿔 보기), ② 단일 모달 모델 앙상블(UME), ③ 단일 모달 보조 손실, ④ 우세 모달리티 기울기 조절(OGM 계열), ⑤ 단일 모달 교사 증류(UMT · CKD 간소판).

## 1. 문제 정의: 모달리티 불균형

### Wang · Tran · Feiszli, What Makes Training Multi-Modal Classification Networks Hard? (CVPR 2020, arXiv 1905.12681) 【초록】
- 출발점이 된 관찰: **가장 좋은 단일 모달 모델이 멀티모달 모델보다 자주 낫다.**
- 원인 두 가지: ① 멀티모달 모델은 용량이 커서 과적합이 쉽다 ② 모달리티마다 과적합 · 일반화 속도가 달라 하나의 최적화 전략으로는 맞지 않는다
- 처방: **Gradient Blending** — 모달리티별 과적합 정도로 손실 가중치를 정해 섞는다

### Wu 외, Characterizing and Overcoming the Greedy Nature of Learning in Multi-modal DNNs (ICML 2022) 【초록】
- 멀티모달 네트워크는 **한 모달리티에 기대고 나머지를 덜 학습하는 탐욕적 경향**이 있다
- **조건부 활용률(conditional utilization rate):** 한 모달리티 가지를 끊었을 때 성능이 얼마나 변하는지로 의존도를 잰다. 예) 깊이 | RGB 0.63, RGB | 깊이 0.01 → 심한 불균형
- 학습 중에는 대리 지표인 **조건부 학습 속도**로 모달리티별 학습 속도를 맞춘다
- **우리에게:** "이미지 활용도"를 직접 재는 지표의 원형 (5절 ①)

### Huang 외, Modality Competition (ICML 2022) 【초록】
- 늦은 결합(late fusion) 모델을 이론적으로 분석: 모달리티들이 **경쟁**하고, 진 모달리티는 끝까지 학습되지 않는다
- 이긴 모달리티는 초기값과 우연히 더 맞았던 쪽일 수 있다 (발표 자료)

### Du 외, On Uni-Modal Feature Learning in Supervised Multi-Modal Learning (ICML 2023) 【본문 일부】
- **모달리티 게으름(Modality Laziness):** 함께 학습하면 각 모달리티의 단독 특징이 충분히 학습되지 않는다
- 두 처방과 선택 기준:
  - **UME (Uni-Modal Ensemble):** 모달리티별로 따로 학습 → 예측을 평균. "교차 모달 상호작용이 중요하지 않고 두 모달리티 모두 단독으로 강하면" 적합
  - **UMT (Uni-Modal Teacher):** 미리 학습한 단일 모달 특징을 늦은 결합 모델의 해당 부분에 증류(MSE, 가중치 50). "단독 특징과 상호작용 특징이 모두 중요하면" 적합
  - 판단법: 고정된 단일 모달 인코더 위의 선형 결합 분류기와 단순 평균을 비교해 결합이 더 나으면 UMT, 아니면 UME
- **우리에게:** 텍스트만 · 이미지만 모델을 따로 학습해 점수를 더하는 것만으로 결합 모델을 이길 수 있는지 확인할 가치가 있다 (5절 ②)

### 추천 분야의 같은 현상
- **Ye 외 2025 (arXiv 2508.07399)** 【본문】: 텍스트가 배우기 쉬워 시각 신호를 덮는다, 이미지 임베딩이 더 흩어져 있다
- **CKD 파일럿 (Zhang 외, ACM MM 2024)** 【본문 일부】: "텍스트만 쓴 VBPR이 멀티모달 VBPR보다 낫다", 모달리티 간 **상호 억제**, 약한 시각 모달리티가 가장 덜 최적화됨

## 2. 우리 데이터 진단 (지금까지의 실험으로 본 것)

| 관찰 | 수치 (main, Recall@300) | 해석 |
|---|---|---|
| 단일 모달 성능 | 이미지만 Marqo **0.1034** > 텍스트만 0.0928 > 이미지만 OpenAI CLIP 0.0806 > 이미지만 ResNet 0.0745 | **우세 모달리티가 인코더에 따라 바뀜.** Marqo에서는 이미지가 우세, ResNet · CLIP에서는 텍스트가 우세 |
| 결합 모델 | 텍스트 + Marqo **0.1056** | 가장 강한 단일 모달(이미지만) 대비 **+2%뿐** → 불균형 · 게으름의 전형적 신호 |
| 이미지 드롭아웃 | 두 기간 모두 개선 (s2 +0.0023, 확증) | **우세 모달리티(이미지) 억제** = OGM 계열 논리와 같은 방향 (사후 해석) |
| 텍스트 드롭아웃 | main +0.0019 → s2 −0.0010 (재현 실패) | 약한 쪽을 더 약하게 만드는 처방이라 불안정한 것과 맞음 (사후 해석) |
| 게이트 결합 | α 평균 0.48, 표준편차 0.02 | 결합 단계에서 모달리티 비중이 상품별로 학습되지 않음 (결정 층 불균형과 관련, 3-2절) |
| 섞은 이미지 대조군 | 텍스트를 가리면 대조군이 "가짜 ID"로 외우기 시작 | 모델이 **상품을 외울 수 있는 벡터면 무엇이든 지름길로 쓴다** → 이미지도 같은 방식으로 외워질 가능성 |

**주의:**
- 이미지만(C1)은 seed 1개, 텍스트만 · 결합은 seed 3개 평균이다.
- 이 표의 해석은 모두 결과를 본 뒤의 것이다. 5절의 실험으로 확인해야 한다.

## 3. 처방의 계보 (BalanceBenchmark 분류)

### BalanceBenchmark: A Survey for Multimodal Imbalance Learning (Xu 외, arXiv 2502.10816, 2025) 【본문 일부】
네 계열로 분류하고 같은 조건에서 비교했다.

| 계열 | 원리 | 대표 방법 |
|---|---|---|
| 데이터 | 약한 모달리티의 표본을 다시 뽑아 강화 | Modality-valuation |
| 순전파 (구조) | 학습 중 특징 · 결합 모듈을 바꿈 | MLA (모달리티 번갈아 학습), Greedy, AMCo, OPM |
| 목표 함수 | 손실에 항을 추가 | **UMT (증류)**, **MMPareto**, **Gradient Blending**, MMCosine, CML, MBSD, LFM |
| 최적화 | 기울기 · 학습 과정 조절 | **OGM (우세 모달리티 기울기 감속)**, AGM, PMR, Relearning, ReconBoost |

**벤치마크 결론 (인용):**
- "거의 모든 관련 방법이 기준(Baseline)보다 낫다". 하지만 표를 보면 **모든 데이터에서 이기는 방법은 없다** (예: AGM은 UCF-101에서 기준보다 낮음)
- 목표 함수 계열은 대부분 데이터에서 좋고, 최적화 계열은 불균형이 작은 데이터에서 낫다
- **"완전한 균형점의 성능은 상대적 균형점보다 낮다"** → 정보량이 큰 모달리티를 과소평가하면 손해. "절대 균형을 맹목적으로 추구하기보다 상대적 균형을 유지하는 것이 낫다"
- "성능과 계산 비용 사이에서 만족스러운 균형을 이룬 방법은 아직 없다". 기존 방법은 전통적 신경망 · 비교적 작은 데이터에 한정

### 대표 방법별 요약
| 방법 | 확인 | 무엇을 하나 | 우리 Two-Tower 적용 |
|---|---|---|---|
| **OGM-GE** (Peng 외, CVPR 2022, oral) | 【초록】 | 모달리티별 기여를 실시간으로 재서 **우세 모달리티의 기울기를 줄이고**, 일반화 저하를 막으려고 동적 가우시안 잡음 추가 | 늦은 결합(텍스트 · 이미지 MLP 분리) 구조가 이미 있어 가능. 비용 낮음 |
| **Gradient Blending** (Wang 외, CVPR 2020) | 【초록】 | 모달리티별 과적합 정도로 손실 가중 | 단일 모달 헤드 필요. 중간 |
| **Greedy 처방** (Wu 외, ICML 2022) | 【초록】 | 모달리티별 학습 속도를 맞춤 | 학습 속도 측정 필요. 중간 |
| **UMT / UME** (Du 외, ICML 2023) | 【본문 일부】 | 단일 모달 특징 증류 / 단일 모달 모델 앙상블 | UME는 **추가 구현이 거의 없음**, UMT는 중간 |
| **MMPareto** (Wei · Hu, ICML 2024) | 【초록】 | 단일 모달 보조 손실과 멀티모달 손실의 **기울기 충돌**을 발견, 모든 목표에 공통인 방향 + 키운 크기로 결합 | 보조 손실 구현 후 추가. 중간 |
| **ReconBoost** (ICML 2024) | 【2차】 | 모달리티를 번갈아 업데이트 (부스팅) | 높음 |
| **결정 층 불균형** (Ma · Chen, arXiv 2510.14411, 2025) | 【초록】 | 균형 있게 학습해도 **결합(결정) 층에서 다시 치우친다**, 결정 층의 적응적 가중 필요 | 우리 게이트 실패와 연결되는 관찰 |

## 4. 추천 시스템에 특화된 방법

### CKD — Modality-Balanced Learning for Multimedia Recommendation (Zhang 외, ACM MM 2024, arXiv 2408.06360) 【본문 일부】
- **단일 모달 교사:** 학생과 같은 구조. 모달리티 m의 교사는 **다른 모달리티 입력을 평균 벡터로 바꿔서**(분포는 유지, 정보는 없음) BPR로 학습
- **증류:**
  - 특정 증류: 학습 쌍 순위에 대한 힌지 손실 max(Δ교사 − Δ학생, 0) → 학생이 교사를 **넘도록**
  - 일반 증류: 무작위 상품 쌍 순위에 대한 교차 엔트로피 (τ = 0.1)
- **반사실 가중:** 모달리티를 평균으로 가렸을 때 점수 변화(평균 처치 효과)를 교사 성능으로 정규화한 ρ. ρ가 낮은(덜 쓰이는) 모달리티에 큰 가중치 λ = 1 − ρ/Σρ
- **결과:** 6개 모델(VBPR, DeepStyle, MMGCN, GRCN, EgoGCN, MGCN), Amazon Beauty · Baby · Clothing · Sports에서 Recall@20 평균 +15.7 ~ 20.9%. VBPR의 **시각 단독 채널 +64.3%**, 텍스트 +28.7%
- **비교 대상:** Gradient Blending, OGM (늦은 결합 모델에만 적용 가능해서 그 경우만 비교)
- **우리에게:**
  - "다른 모달리티를 평균으로 바꿔 효과를 잰다"는 방식은 **이미지 활용도 진단 지표**로 그대로 쓸 수 있다 (5절 ①)
  - 교사 증류는 간소판으로 시험 가능 (5절 ⑤)

### Mirror Gradient (Zhong 외, WWW 2024, arXiv 2402.11262) 【초록】
- 멀티모달 입력의 잡음 · 정보 조정 위험에 대한 **강건성**을 목표로, 학습 중 기울기 부호를 적절히 뒤집어 평평한 최소점으로 유도
- 여러 모델에 붙여 쓸 수 있으나 저장소 보고 수치는 작은 개선 (예: BM3 Recall 0.0280 → 0.0285)
- **우리에게:** 활용도보다 강건성 쪽이라 우선순위 낮음

### 정렬 계열: AlignRec (CIKM 2024) 【2차】 · AnchorRec (arXiv 2603.12726, 2026) 【본문 일부】
- AlignRec: 콘텐츠 내부 · 콘텐츠-ID · 사용자-상품 정렬
- AnchorRec의 비판:
  - 정렬 기반 방법은 한 상품의 모달리티별 임베딩을 **거의 같은 위치로 무너뜨리고(positional collapse)**
  - BPR 학습 때문에 최종 임베딩이 **ID 패턴에 치우친다(ID dominance)**
  - 처방: 가벼운 투영 공간에서 앵커 정렬 + 사전학습 유사도 구조 보존 손실
- **우리에게:** 정렬을 추가할 때 이미지 고유 구조를 지우지 않도록 주의. 우리는 ID가 없으니 ID 지배 문제는 작지만, 섞은 이미지가 가짜 ID처럼 쓰인 것과 같은 지름길 위험은 있다

### 콘텐츠-협업 신호 결합: CLCRec (Wei 외, ACM MM 2021) 【초록】
- 콜드스타트 상품 표현을 **콘텐츠와 협업 신호의 상호정보 최대화**로 학습 (대조 학습)
- **우리에게:** 이미지 표현이 구매 패턴과 맞물리도록 하는 보조 목표의 근거

### 모달리티 드롭아웃 계열 (이미 시험함)
- LRMM (EMNLP 2018), SMD (CIKM 2026), DropoutNet (NeurIPS 2017) — [선행연구조사.md](선행연구조사.md) 4절
- 우리 결과: 이미지 드롭아웃 확증, 텍스트 드롭아웃 재현 실패

### 상품별 게이트: VisGate (CARS@RecSys 2026) 【초록】
- 사용자 맥락까지 넣은 게이트. 우리 게이트(상품 특징만)는 실패 → 결정 층 불균형 연구와 함께 보면 **"결합 단계에서 무엇을 보고 비중을 정하는가"** 가 핵심

## 5. 우리 연구에 주는 함의와 다음 실험 후보

### 연구 질문 다듬기
> "텍스트와 이미지를 함께 학습하면 한 모달리티가 학습을 장악해(모달리티 불균형), 결합 모델이 가장 강한 단일 모달을 거의 넘지 못한다. 어떤 학습 처방이 이를 완화해 **두 모달리티를 모두 활용하는** 추천 모델을 만드는가?"

"이미지 활용도"를 성능 하나로만 보지 않고, **① 결합 모델의 성능**과 **② 모델이 실제로 이미지에 기대는 정도**를 함께 잰다.

### 실험 후보 (비용 · 우선순위 순)
| # | 후보 | 근거 | 무엇을 재나 | 비용 |
|---|---|---|---|---|
| ① | **이미지 활용도 진단 지표:** 추천할 때 이미지(또는 텍스트) 입력을 전체 평균 벡터로 바꿨을 때의 성능 하락 | Wu 외 조건부 활용률, CKD 반사실 효과 | 모델이 실제로 이미지를 얼마나 쓰는지 (기존 "섞은 이미지 대조군"은 별도 모델이 필요하고 가짜 ID 문제가 있음) | **매우 낮음.** 예측 함수에 옵션 하나, 재학습 없이 같은 모델에서 측정 |
| ② | **UME:** 텍스트만 · 이미지만 모델을 따로 학습해 점수를 합산 | Du 외 2023 | 결합 학습 없이도 결합 모델을 이기는가 → 불균형의 크기 | 낮음 (점수 합산 예측 구현) |
| ③ | **단일 모달 보조 손실:** 늦은 결합 구조에서 텍스트 · 이미지 가지마다 자체 손실 추가 | MMPareto의 설정, Gradient Blending | 각 가지가 단독으로도 학습되면 결합이 나아지는가 | 낮음 |
| ④ | **우세 모달리티 기울기 조절 (OGM 계열):** 기여가 큰 가지의 기울기를 줄임 | OGM-GE | 학습 과정에서 균형을 맞추면 나아지는가. 인코더별로 우세 방향이 다르므로 Marqo(이미지 우세) · ResNet(텍스트 우세) 둘 다 확인 | 중간 |
| ⑤ | **단일 모달 교사 증류 (UMT · CKD 간소판)** | Du 외 UMT, CKD | 교사를 넘도록 학습하면 각 모달리티 활용이 오르는가 | 중간 |

### 진행 원칙
- **①을 먼저:** 다른 모든 실험의 "활용도"를 같은 잣대로 잴 수 있다.
- ② ~ ⑤는 같은 테스트 주(s2)에서 사전 등록 후 실행하고, 확증은 1 ~ 2개만.
- 벤치마크 교훈대로 "완전한 균형"을 목표로 하지 않는다. 판정은 **결합 모델 성능**으로 하고, 활용도 지표는 설명용으로 쓴다.
- 이미지 드롭아웃(확증된 처방)과 함께 쓸 때 효과가 겹치는지도 본다.
