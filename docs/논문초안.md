# 패션 추천에서 이미지를 어떻게 쓸 것인가: 텍스트와의 결합 방식과 이미지 인코더 선택

김유환 · 김형우 · 김광석 (서강대학교)

## 요약

멀티모달 추천 모델이 이미지를 충분히 활용하지 못한다는 보고가 있다. 본 연구는 상품 ID를 사용하지 않는 콘텐츠 기반 후보 생성 모델에서 (RQ1) 이미지와 텍스트의 결합 방식과 (RQ2) 이미지 인코더의 선택이 추천 성능에 미치는 영향을 분석한다. H&M 구매 데이터에서 Two-Tower 모델의 한 요인씩 변경하여 비교하고 확증 가설은 사전 등록하여 검정하였다. 두 모달리티의 임베딩을 연결하여 하나의 모델로 학습하는 이른 결합은 텍스트 단일 모델 대비 Recall@300을 13 ~ 15% 향상시킨 반면, 모달리티별 모델을 별도로 학습한 뒤 고객별 표준화 점수를 합산하는 늦은 결합은 테스트 주가 다른 네 분할에서 모두 약 39% 향상시켰다. 이 차이는 모델 수를 통제한 앙상블이나 동일한 예산으로 규제를 튜닝한 공동 학습 모델로 설명되지 않았으며, MAP@12에서도 유지되었다. 이미지 인코더의 경우 사전학습 데이터의 변경은 이미지 기여도를 약 2배 높였으나 패션 도메인 추가 학습의 효과는 확인되지 않았고, 이미지 기여도는 구매 이력이 적은 상품에서 더 컸다.

## 1. 서론

멀티모달 추천은 상품의 이미지와 텍스트를 활용하여 표현력을 높이고 신규 상품에 대응하는 것을 목표로 한다 [6, 7]. 그러나 Ye 외 [1]는 다수의 멀티모달 추천 모델에서 이미지를 제거하여도 성능 변화가 작다고 보고하였다. 일반 멀티모달 학습에서도 여러 모달리티를 하나의 모델로 학습하면 학습이 쉬운 모달리티에 의존하는 **모달리티 불균형**이 나타난다 [3 – 5]. 따라서 추천에서 이미지 활용도가 낮은 원인은 이미지 정보 자체보다 결합 방식이나 임베딩 방식에 있을 수 있다.

모달리티를 입력 단계에서 결합하는 이른 결합과 예측 단계에서 결합하는 늦은 결합은 멀티미디어 분야에서 오랫동안 비교되어 왔으며 [2], 추천 모델에서도 두 방식이 모두 사용된다 [6 – 9]. 그러나 모델 수를 통제한 비교와 늦은 결합의 설계 방안을 체계적으로 다룬 연구는 많지 않다. 본 연구는 신규 상품 추천이 가능한 **ID 비사용 후보 생성 모델** [11, 12]을 대상으로 두 연구 질문을 다룬다. RQ1은 이미지와 텍스트를 공동으로 학습할 것인지 모달리티별로 학습할 것인지, 그리고 모달리티별로 학습한다면 어떻게 결합할 것인지이다. RQ2는 이미지 임베딩에 사용할 인코더와 이미지가 중요한 상품의 특성이다. 본 연구의 기여는 다음과 같다.
1. 늦은 결합이 이른 결합보다 크게 우수하며(텍스트 단일 모델 대비 +39% 대 +13 ~ 15%), 이 차이가 모델 수, 동일 모달리티 앙상블, 규제 튜닝으로 설명되지 않고 MAP@12에서도 유지됨을 사전 등록 검정으로 확인하였다.
2. 점수 정규화, 가중치, 이미지 인코더, 모델 수, 베이스라인과의 결합 위치를 비교하여 늦은 결합의 **설계 지침**을 제시하였다.
3. 이미지 인코더 6종을 비교하여 패션 도메인 적응보다 **사전학습 데이터**가 이미지 기여도와 더 밀접하며, 이미지가 **구매 이력이 적은 상품**에서 더 중요함을 보였다.

## 2. 관련 연구

### 2.1 멀티모달 추천

VBPR [6]은 사전학습된 이미지 특징을 상품 표현에 연결하는 이른 결합을, MMGCN [7]은 모달리티별 그래프에서 표현을 각각 학습한 뒤 결합하는 방식을 사용하였다. LATTICE [8]와 FREEDOM [9]은 모달리티 유사도에 기반한 상품 그래프로 성능을 개선하였고, 서베이 [10]는 결합 시점을 주요 설계 요소로 정리하였으며, 패션 분야에서는 이미지 특징을 추천 목적에 맞게 직접 학습하기도 하였다 [13]. 다만 이들 모델은 대부분 ID 임베딩과 함께 사용되어 이미지의 역할을 분리하여 평가하기 어렵다. Yuan 외 [12]는 ID 없이 콘텐츠만으로 ID 기반 모델에 근접한 성능을 보였고, DropoutNet [11]은 콘텐츠 기반 표현으로 신규 상품 문제에 대응하였다.

### 2.2 모달리티 불균형

Ye 외 [1]는 추천 모델에서 텍스트 신호가 시각 신호를 압도한다고 해석하였다. Wang 외 [3]는 분류 문제에서 멀티모달 모델이 단일 모달 모델보다 낮은 성능을 보이는 사례를, Wu 외 [4]와 Du 외 [5]는 특정 모달리티에 편향된 학습을 보고하였다. Du 외 [5]는 모달리티별 모델을 별도로 학습한 뒤 예측을 결합하는 UME(Uni-Modal Ensemble)를 제안하였으며, 추천 분야에서는 단일 모달 교사 모델을 이용한 지식 증류가 제안되었다 [14]. 본 연구의 늦은 결합은 [5]의 UME에 해당하며, 본 연구는 이를 추천 문제에서 통제된 조건으로 검증하고 설계 지침을 제시한다.

## 3. 방법

### 3.1 모델

ID를 사용하지 않는 Two-Tower 모델을 사용한다. 상품 타워는 상품의 콘텐츠 임베딩을, 고객 타워는 최근 구매한 상품 최대 50개의 임베딩 평균을 입력으로 받아 MLP(은닉 512, 출력 128)로 변환하며, 정규화된 내적을 점수로 하여 배치 내 softmax 손실로 학습한다.

### 3.2 결합 방식

그림 1의 세 방식을 비교한다. (a) **이른 결합**(공동 학습)은 텍스트와 이미지 임베딩(각 256차원)을 연결하여 하나의 모델로 학습한다. (b) **늦은 결합**(UME)은 텍스트 모델(T)과 이미지 모델(I)을 별도로 학습한 뒤, 고객 u의 전체 상품 점수 s<sub>u</sub><sup>m</sup>(i)를 모델별로 <span class="nw">z<sub>u</sub><sup>m</sup>(i) = (s<sub>u</sub><sup>m</sup>(i) − μ<sub>u</sub><sup>m</sup>) / σ<sub>u</sub><sup>m</sup></span>로 표준화하고 <span class="nw">z<sup>T</sup> + w · z<sup>I</sup></span> (w = 1)가 큰 상위 300개를 추천한다. (c) **앙상블 대조군**은 동일한 모델 두 개(seed만 상이)를 (b)와 같은 방식으로 결합하여 모델 수 증가의 효과를 분리한다. 모든 결과는 seed 42 · 43 · 44의 평균이며, UME는 같은 seed의 모델끼리, 앙상블은 (42, 43) · (43, 44) · (44, 42) 세 쌍으로 구성한다.

### 3.3 이미지 기여도

이미지 인코더만 달리한 이른 결합 모델을, 상품 간 이미지 임베딩을 무작위로 섞어 학습한 대조 모델과 비교한다. 절대 기여도는 <span class="nw">R<sub>실제</sub> − R<sub>섞음</sub></span>, 상대 기여도는 <span class="nw">(R<sub>실제</sub> − R<sub>섞음</sub>) / R<sub>섞음</sub></span>으로 정의한다.

### 3.4 평가 및 사전 등록

콘텐츠 모델을 후보 생성 단계로 간주하여 고객별 평균 Recall@300(R)을 주 지표로, H&M 대회 지표인 MAP@12를 상위 추천 품질 지표로 사용한다. 상품은 학습 데이터의 판매 횟수에 따라 기존(10회 이상), 희소(1 ~ 9회), 신규(테스트 주 첫 판매)로 구분한다. 차이의 신뢰구간은 고객 단위 짝지은 부트스트랩(1,000회)으로 추정한다. 확증 가설은 판정 기준과 함께 실험 전에 저장소에 커밋하였고, 등록 시점에 해당 테스트 주에서 이미 확인한 결과를 함께 기록하였다. 등록된 검정 수에 따라 본페로니 보정을 적용하여 신뢰구간 하한이 0보다 크면 지지로 판정하였으며, 그 외 비교는 탐색적 결과로서 95% 신뢰구간만 보고한다.

## 4. 실험 설정

H&M 구매 기록 31,788,324건 [17] 중 이미지가 있는 상품 53,232개와 학습 기간 구매가 5회 이상인 고객을 사용하였다. 학습 26주, 검증 1주, 테스트 1주로 구성하되 테스트 주를 2주씩 이동한 네 분할을 사용하였다: main(2020-09-16 ~ 22, 테스트 고객 46,054명), s2(09-02 ~ 08, 50,904명), s4(08-19 ~ 25, 49,061명), s6(08-05 ~ 11, 49,846명). 네 분할은 학습 기간이 대부분 겹치므로 독립적인 재현이 아닌 반복 측정으로 해석한다. 텍스트 임베딩은 all-MiniLM-L6-v2(상품명 · 품목 · 색상 · 설명), 이미지 임베딩은 Marqo-FashionSigLIP [15]을 기본으로 하여 표 2의 인코더와 비교하였으며, 모든 임베딩은 PCA로 256차원으로 축소한 뒤 L2 정규화하였다. 학습률 0.0005, 8 에폭, 배치 2,048, 온도 0.05를 검증 주 기준으로 선택하였고, 동일 조건의 재학습 22회에서 추천 결과가 모두 일치하였다. 규제 튜닝 비교에서는 세 모델 모두 드롭아웃 · weight decay · 에폭의 18개 조합을 s6 검증 주에서 동일한 예산으로 탐색하였다.

## 5. 실험 결과

### 5.1 결합 방식 (RQ1)

#### 5.1.1 이른 결합의 한계

이미지 단일 모델은 네 분할 모두에서 텍스트 단일 모델보다 7 ~ 12% 높아 이미지가 유용한 정보를 담고 있음을 보였다. 그러나 이른 결합은 이미지 단일 모델보다 3 ~ 5% 높은 데 그쳤다(표 1). 구매 단위로 분석하면 텍스트 모델과 이미지 모델이 맞힌 구매의 Jaccard 유사도(0.31 ~ 0.34)는 같은 모달리티의 서로 다른 seed 간 유사도(0.45 ~ 0.57)보다 낮아, 두 모달리티가 서로 다른 구매를 예측함을 시사한다. 한쪽 모델만 맞힌 구매 중 UME(모델 2개)는 63 ~ 70%를 유지한 반면, 이른 결합은 텍스트 모델만 맞힌 구매의 32 ~ 33%, 이미지 모델만 맞힌 구매의 43 ~ 51%만 유지하였다(탐색적 분석).

#### 5.1.2 늦은 결합의 효과

UME는 네 분할 모두에서 텍스트 단일 모델 대비 약 39% 높았다(표 1). 사전 등록 당시 결과를 확인하지 않은 s4에서 UME는 이른 결합보다 R이 +0.0210 [+0.0197, +0.0224] 높았다. s2에서는 모델 수를 맞춘 이른 결합 × 2보다 **+0.0080** [+0.0066, +0.0096], 동일 모달리티 조합 중 가장 강한 이미지 × 2보다 **+0.0165** [+0.0151, +0.0178] 높았으며(98.33% 구간), main에서도 각각 +0.0079, +0.0180이었다(탐색적). 따라서 UME의 이득은 모델 수 증가만으로 설명되지 않는다. 새 분할 s6에서 세 모델을 동일한 격자로 튜닝한 뒤에도 UME는 튜닝된 이른 결합보다 Recall@300이 **+0.0148** [+0.0134, +0.0160], 튜닝된 이른 결합 × 2보다 **+0.0076** [+0.0062, +0.0090], MAP@12가 **+0.0015** [+0.0011, +0.0018] 높았다(사전 등록, 98.33% 구간). MAP@12의 우위는 main · s2 · s4에서도 +0.0022 ~ +0.0024로 관찰되었다(탐색적). 튜닝으로 이른 결합의 과적합 정도(학습 주와 테스트 주의 R 차이)는 0.055에서 0.033으로 감소하였으나 UME의 우위는 유지되었다. 반면 단일 모델 안에서 모달리티 균형을 조정하는 기법(드롭아웃, 잡음, 게이트 등 사전 등록 8건)은 효과가 작거나 다른 주에서 재현되지 않았다.

#### 5.1.3 늦은 결합의 설계

탐색적 비교에서 다음 지침을 도출하였다. 첫째, 두 모델의 점수는 동일한 가중치로 합산하는 것이 적절하다. w ∈ {0.5, 1, 2} 중 w = 1이 가장 높았고, z 표준화 대신 원점수나 min-max 정규화를 사용하여도 차이는 0.0006 이하였으나, 순위만 사용하는 RRF는 Recall@300이 0.011 ~ 0.016 낮았다(네 분할). 둘째, 이미지 모델에는 대규모 사전학습 인코더가 적합하다. 범용 SigLIP과 Marqo의 차이는 유의하지 않았으나(−0.0005 [−0.0012, +0.0001]) ResNet-50은 0.011 낮아 5.2.1절의 인코더 순위와 일치하였다. 셋째, 모델을 추가할 때에도 모달리티를 구분한다. 텍스트 · Marqo · ResNet 세 모델의 결합은 이른 결합 세 개의 앙상블보다 +0.0065 [+0.0050, +0.0081] 높았으나, 이미지 인코더 두 개의 결합(s4, 0.1030)은 텍스트 · 이미지 결합(0.1177)보다 낮았다. 넷째, UME의 이득은 주로 기존 상품에서 발생하였으며, 신규 상품에서는 이른 결합 × 2가 더 높았다(s2, 텍스트 단일 대비 +0.032 대 +0.024).

#### 5.1.4 베이스라인과의 결합

재구매와 인기도 기반 베이스라인(B2)은 모든 콘텐츠 모델보다 높은 성능을 보였다(s2 · main 0.257, s4 0.208, s6 0.199). B2의 상위 280개에 UME 후보 20개를 추가하면 s4에서 B2보다 **+0.0091** [+0.0081, +0.0101] 높았고(사전 등록, 97.5% 구간), s2 · main · s6에서도 각각 +0.0027, +0.0068, +0.0074였다(탐색적). 같은 위치를 이른 결합 후보로 채운 경우보다 UME 후보가 우수하였다(s2, 사전 등록, +0.0097 [+0.0088, +0.0107]). 추가 20자리를 희소 · 신규 상품 전용으로 사용하면 전체 성능은 B2보다 0.0035 낮았으나 신규 상품 재현율은 0.033 향상되었다(s4, 사전 등록).

### 5.2 이미지 임베딩 (RQ2)

#### 5.2.1 사전학습 데이터와 패션 도메인 적응

이미지 인코더는 기여도에 따라 두 집단으로 구분되었다(표 2). 출발점이 같은 범용 · 패션 적응 인코더 두 쌍에서 패션 적응의 추가 효과는 확인되지 않았다(Marqo − SigLIP +0.0014 [−0.0218, +0.0237], 사전 등록 불지지; FashionCLIP − LAION CLIP +0.0026). 반면 동일한 CLIP B/32 구조에서 사전학습 데이터를 OpenAI에서 LAION-2B로 변경하면 상대 기여도가 약 2배 증가하였다(s2, 사전 등록, 0.105 → 0.212, +0.106 [+0.080, +0.131]). 다만 두 데이터는 규모와 구성이 함께 달라 원인을 단일 요인으로 특정할 수 없다.

#### 5.2.2 구매 이력에 따른 이미지 기여도

모든 인코더에서 희소 · 신규 상품의 상대 기여도는 기존 상품의 2배 이상이었다(표 2). Marqo의 절대 기여도 역시 희소 상품이 기존 상품의 약 2배였다(s2, 사전 등록, +0.0129 [+0.0073, +0.0178]).

#### 5.2.3 텍스트 정보와 이미지 기여도

이미지가 텍스트에 없는 정보를 보완한다면 상품 설명에 패턴이 언급되지 않은 패턴 상품에서 이미지 기여도가 더 커야 한다. 상품 설명에 대한 키워드 규칙으로 상품을 구분하였으며(표본 100개 AI 보조 판정과 불일치 0건, 미언급 2건은 상품명에 패턴 포함), 품목 내 이미지 섞기 대조군 대비 기여도는 오히려 언급 상품에서 더 컸다(main, −0.0131 [−0.0205, −0.0063]). 입력 텍스트 전체의 패턴 단어를 마스킹한 뒤 재학습하여도 기여도 증가는 확인되지 않았고(+0.0033 [−0.0011, +0.0074]), 시각적으로 일관된 구매 이력을 가진 고객에서의 차이도 유의하지 않았다(+0.0066 [−0.0099, +0.0226]). 이미지가 텍스트의 누락 정보를 보완한다는 근거는 확인되지 않았다.

## 6. 결론 및 한계

본 연구는 H&M 데이터와 ID 비사용 Two-Tower 모델에서 이미지의 결합 방식과 임베딩 방식을 분석하였다. 늦은 결합은 텍스트 단일 모델 대비 약 39% 향상되어 이른 결합(13 ~ 15%)보다 우수하였고, 이 차이는 모델 수 증가나 규제 부족으로 설명되지 않았으며 MAP@12에서도 유지되었다. 결합 시에는 순위가 아닌 점수를 동일 가중치로 합산하는 것이 효과적이었다(RQ1). 이미지 인코더는 패션 도메인 적응 여부보다 사전학습 데이터와 밀접하였고, 이미지는 구매 이력이 적은 상품에서 더 중요하였다(RQ2).

본 연구는 단일 데이터셋과 모델 구조를 사용하였고 네 분할의 학습 기간이 중복된다. 콘텐츠 모델 단독 성능은 베이스라인보다 낮고 MAP@12 절댓값(0.006 ~ 0.008)도 작아 결론은 후보 생성과 신규 상품 추천 단계에 한정된다. 결합 설계 지침은 탐색적 비교에 근거하며, 임베딩은 인코더 선택만 비교하였다. UME의 추론 시간은 CPU 단일 스레드에서 고객당 중앙값 6.4ms로 공동 학습(2.8ms)의 약 2.3배였다(API 전체 지연 제외). 코드, 사전 등록 파일, 가설별 대응표와 검정 결과는 https://github.com/3sunghynix/multimodal-recsys 에 공개한다.
