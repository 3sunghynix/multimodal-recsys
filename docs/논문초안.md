# 패션 추천에서 이미지는 언제 도움이 되는가: 인코더, 상품 ID, 구매 기록의 조건 분석

김유환 · 김형우 · 김광석 (소속 【미정】)

## 요약

최근 멀티모달 추천 연구는 모델이 텍스트에 의존하고 이미지 정보를 거의 활용하지 못한다고 보고했다. 그러나 이 결론은 범용 이미지 특징, 상품 ID를 쓰는 모델, 학습에 등장한 상품만의 평가라는 조건에서 얻어졌다. 본 연구는 H&M 실구매 데이터(테스트 고객 46,054명)에서 ID를 쓰지 않는 Two-Tower 모델에 텍스트와 이미지 임베딩을 입력하고, 입력 크기가 같은 섞은 이미지 대조군 대비 이미지 기여도를 측정했다. 두 단계로 사전 등록한 세 가설 — 패턴 상품에서의 기여 증가, 패션 도메인 적응의 효과, 상품 ID의 가림 효과 — 은 모두 지지되지 않았다(도메인 적응 두 쌍 차이 +0.001·+0.003; 차이의 97.5% 구간이 약 −0.02 ~ +0.03에 걸쳐 있어 이 범위의 효과는 배제하지 못한다). 대신 사후 탐색적 분석에서 세 조건이 이미지 기여를 크게 갈랐다: 같은 CLIP ViT-B/32 구조에서 사전학습 데이터가 다르면 기여가 약 2배 달랐고, 구매 기록이 적은 상품에서 기여가 약 2배 이상이었으며, 상품 ID를 드롭아웃 없이 쓰면 기존 상품의 기여가 약 25% 줄었다. 세 조건 모두 선행 연구의 설정(구세대 인코더, 기존 상품 중심 평가, ID를 그대로 사용)에서 이미지 기여가 작아지는 방향으로 정렬되는 경향이 탐색적으로 관찰됐다. 이 결과는 "이미지는 추천에 기여하지 않는다"는 결론이 인코더의 사전학습, 평가 대상 상품, ID 사용 방식에 따라 달라질 수 있음을 시사한다.

## 1. 서론

멀티모달 추천은 상품의 이미지와 텍스트 임베딩을 함께 사용해 추천 성능과 신규 상품 대응력을 높이려 한다. 그런데 Ye 외 [1]는 멀티모달 추천 모델 14개를 분석해, 모델들이 "텍스트 지배" 상태로 작동하며 시각 신호는 대부분 활용되지 않는다고 보고했다. 이 분석은 Amazon 데이터셋과 MMRec 벤치마크가 제공하는 ResNet-50 이미지 특징을 사용했고, 대상 모델은 모두 상품 ID 임베딩을 함께 사용하며, 평가는 학습에 등장한 상품으로 이뤄졌다.

같은 질문을 H&M 실구매 데이터로 측정한 우리의 예비 실험에서는 이미지가 텍스트 위에 뚜렷하게 기여했다 (텍스트만 대비 Recall@300 +14%, 신규 상품 +46%; 본문 표 1의 상대 기여도는 섞은 이미지 대비로 측정 방식이 다르며, 이 서론 수치는 동기 서술에만 쓴다). 두 결과는 데이터, 모델, 인코더, 평가 대상이 모두 다르다. 이에 본 연구는 **이미지의 기여가 어떤 조건에서 나타나는가**를 묻는다.

본 연구의 기여는 다음과 같다.
- 입력 크기가 같은 **섞은 이미지 대조군**으로, 모델이 이미지 내용을 실제로 사용하는 정도를 측정했다.
- 출발점이 같은 범용 대 패션 적응 인코더 **두 쌍**으로 도메인 적응의 효과를 분리해 검증했다.
- 가설을 **두 단계로 사전 등록**하고, 지지되지 않은 결과를 포함해 모두 보고했다. 사후 분석은 탐색적으로 구분했다.
- 사후·탐색적 분석에서 이미지 기여를 가른 **세 조건**(인코더 사전학습, 상품 구매 기록의 양, ID 사용 방식)을 관찰했으며, 세 조건 모두 선행 연구 [1]의 조건에서 이미지 기여가 작아지는 방향으로 정렬되는 경향을 보였다.

## 2. 관련 연구

**멀티모달 추천의 이미지 활용.** Ye 외 [1]는 Amazon Baby · Sports · Clothing에서 이미지와 텍스트 임베딩을 노이즈로 바꾸는 방식으로 각 모달리티의 기여를 측정했고, 대부분의 모델에서 이미지를 제거해도 영향이 작았다. 다만 이미지에 민감한 일부 모델(GRCN, LGMRec)은 Clothing에서 이미지를 제거하면 NDCG@10이 11~14% 하락했다. 이 연구의 기여도 측정은 ResNet-50 특징으로 이뤄졌다.

**ID 대 콘텐츠.** 상품 ID 없이 콘텐츠 인코더만으로 ID 기반 모델에 근접할 수 있다는 연구 [2]와 ID 없는 멀티모달 추천 [3]이 보고됐다 【확인 필요】. 시각 정보의 유용성이 상품 수준에서 달라진다는 연구도 있다 [4] 【확인 필요】.

**패션 적응 인코더.** Marqo-FashionSigLIP은 SigLIP ViT-B/16(WebLI)에서 패션 상품 데이터로 추가 학습한 모델이고 [5], FashionCLIP 2.0은 LAION-2B로 학습된 CLIP ViT-B/32에서 Farfetch 상품 80만 개 이상으로 추가 학습한 모델이다 [6].

## 3. 방법

**모델.** ID를 쓰지 않는 Two-Tower 모델을 사용한다. 상품 타워는 상품의 텍스트 임베딩과 이미지 임베딩을 이어 붙여 MLP에 입력하고, 고객 타워는 고객이 최근 구매한 상품(최대 50개)의 상품 입력 평균을 MLP에 입력한다. 배치 내 다른 상품을 부정 샘플로 하는 softmax로 학습한다. 학습 표본은 주 단위로 만들며, 각 주의 구매를 정답으로 하고 그 주 이전 구매만 이력으로 사용해 미래 정보가 섞이지 않게 한다.

**ID 모델.** 상품 타워 입력에 학습되는 상품 ID 임베딩을 추가한 모델도 사용한다. 학습 데이터에 없는 상품의 ID는 0으로 두고, 학습 중 확률 p로 ID 부분을 0으로 바꾸는 ID 드롭아웃을 둔다. 고객 쪽에는 ID를 쓰지 않으므로, 고객과 상품 모두 ID를 쓰는 [1]의 모델과는 다르다.

**이미지 기여도.** 상품마다 다른 상품의 이미지 임베딩을 무작위로 배정한 **섞은 이미지** 조건을 대조군으로 둔다. 입력 크기가 같으므로 "입력이 커져서 생긴 효과"가 통제된다. 이미지 기여도를 다음과 같이 정의한다.

- 상대 기여도 = [R(텍스트 + 이미지) − R(텍스트 + 섞은 이미지)] ÷ R(텍스트 + 섞은 이미지)
- 절대 기여도 = R(텍스트 + 이미지) − R(텍스트 + 섞은 이미지)

R은 고객별 평균 Recall@300이다. 구간별로 잴 때는 분자와 분모를 모두 그 구간의 구매로만 계산한다.

**사전 등록.** 1차 사전 등록은 "같은 상품군 안에서 이미지 기여가 패턴 상품에서 무지 상품보다 크다"였다. 이 가설이 지지되지 않은 뒤 질문을 넓혀 2차 사전 등록을 했다.
- H1(도메인 적응): 구조가 같은 쌍에서 패션 적응 모델의 상대 기여도가 범용 모델보다 크다.
- H2(ID의 가림): 기존 상품에서 ID 없는 모델의 상대 기여도가 ID 있는 모델보다 크다.

두 가설, 측정값, 판정 기준, ID 설정 선택 규칙은 모두 해당 실험을 실행하기 전에 저장소에 커밋했다. 확증 검정은 고객 단위 짝지은 부트스트랩(1,000회)으로 차이의 구간을 구하고, 두 검정에 본페로니 보정을 적용해 97.5% 구간의 하한이 0보다 크면 지지로 판정한다.

## 4. 실험 설정

**데이터.** H&M 구매 기록 31,788,324건(2018-09-20 ~ 2020-09-22)을 사용했다 【확인 필요: 데이터 이용 조건】. 분할 기간에 팔렸고 이미지가 있는 상품 53,232개와, 학습 기간 구매가 5회 이상인 고객 450,766명을 대상으로 했다. 시간 기준으로 학습 26주(2020-03-11 ~ 09-08), 검증 1주, 테스트 1주(2020-09-16 ~ 22)로 나눴다. 테스트는 고객 46,054명의 구매 150,415건이다. 학습 데이터 판매 횟수를 기준으로 기존 상품(10회 이상, 136,816건), 희소 상품(1~9회, 7,167건), 신규 상품(테스트 주에 처음 판매, 6,144건)으로 구분했다.

**인코더.** 텍스트는 all-MiniLM-L6-v2로 상품명 · 품목 · 색상 · 설명을 임베딩했다. 이미지는 주 쌍(SigLIP ViT-B/16 WebLI 대 Marqo-FashionSigLIP)과 재현 쌍(CLIP ViT-B/32 LAION-2B 대 FashionCLIP 2.0)을 사용했고, 참고로 ResNet-50(ImageNet)과 CLIP ViT-B/32(OpenAI)를 비교했다. 모든 임베딩은 PCA로 256차원으로 줄인 뒤 L2 정규화했다.

**학습.** 은닉 512, 출력 128, 학습률 0.0005, 8에폭, 배치 2,048, 온도 0.05이며 검증 주로 선택했다. ID 모델은 후보 4개 중 검증 주 성능이 가장 높은 ID 크기 64, 드롭아웃 0.3을 사전 등록 규칙에 따라 선택했다. 모든 조건을 seed 3개(42, 43, 44)로 학습하고 평균했다. 계산은 NVIDIA L4 GPU 1장으로 했다.

## 5. 결과

**표 1.** 조건별 이미지 상대 기여도 (섞은 이미지 대비, seed 3개 평균)

| 이미지 인코더 | 사전학습 | ID 없음 · 전체 | ID 없음 · 기존 상품 | ID(p=0.3) · 기존 상품 | ID(p=0) · 기존 상품 |
|---|---|---|---|---|---|
| ResNet-50 | ImageNet | 0.090 | 0.079 | — | — |
| CLIP ViT-B/32 | OpenAI | 0.092 | 0.076 | — | — |
| CLIP ViT-B/32 | LAION-2B | 0.179 | 0.157 | — | — |
| FashionCLIP 2.0 | LAION-2B + 패션 | 0.182 | 0.162 | — | — |
| SigLIP ViT-B/16 | WebLI | 0.186 | 0.165 | 0.197 | 0.134 |
| Marqo-FashionSigLIP | WebLI + 패션 | 0.187 | 0.167 | 0.162 | 0.126 |

**확증 검정.** H1은 지지되지 않았다. Marqo와 범용 SigLIP의 상대 기여도 차이는 +0.0014(97.5% 구간 [−0.0218, +0.0237])였고, 재현 쌍(FashionCLIP 2.0 − LAION CLIP)도 +0.0026(95% 구간 [−0.0149, +0.0219])으로 같은 방향이면서 거의 0이었다. H2도 지지되지 않았다. 기존 상품에서 ID 없는 모델과 선택 설정(p=0.3)의 ID 모델의 차이는 +0.0046(97.5% 구간 [−0.0200, +0.0308])이었다. 1차 사전 등록 가설(패턴 대 무지)도 지지되지 않았다: 상품군 가중 차이 +0.0018(95% 구간 [−0.0009, +0.0051]). 이 결과가 라벨 노이즈에서 기인하는지 점검하기 위해 외관 그룹별 40장씩 총 120장의 상품을 저자 1인이 검수했다(판정자가 원 라벨을 격자 캡션에서 볼 수 있는 방식이라 라벨 확증 편향 가능성이 있어, 관찰된 불일치율은 하한으로 해석해야 한다. 판정 기준: 이미지가 `graphical_appearance_name` 라벨과 일치하는지). 검사 표본의 라벨 일치율은 90.8%(109/120)이며, pattern 그룹만 77.5%(31/40)로 낮았다. 오분류의 방향은 대부분 "패턴이 아닌데 패턴으로 분류"였고, 이는 관측된 패턴 − 무지 차이를 실제보다 **0 쪽으로 줄이는** 방향이다. 오라벨로 판정된 11개 상품의 구매 34건을 정답에서 제외해도 결과는 사실상 동일했으나(+0.0018 [−0.0009, +0.0050]) 이는 표본에서 확인된 오라벨의 상한만을 다룬다. 더 보수적으로, pattern 그룹에서 오분류가 몰린 원 라벨(`All over pattern`)에 해당하는 상품 8,470개 전부를 제외해도 결론(불지지)은 유지됐다(+0.0009 [−0.0023, +0.0049]). 이 상한 시나리오에서 점추정이 반감된 것은 `All over pattern`이 pattern 그룹의 큰 비중을 차지해 오분류 교정과 그룹 축소 효과가 섞인 결과이지만, CI 상한(+0.0049)이 원본(+0.0051)과 거의 같아 숨은 큰 효과의 가능성은 낮다. 라벨 오분류는 패턴 − 무지 차이를 줄이는 방향이므로 불지지 결과는 이 편향을 감안해 해석해야 하며, 검사되지 않은 상품의 라벨 노이즈까지 배제할 수는 없다.

**사후 탐색적 분석.** 결과를 본 뒤 정한 비교이므로 다중 비교 보정 없이 95% 구간만 보고한다 (그림 1).
- **사전학습:** 구조가 같은 CLIP ViT-B/32에서 LAION-2B 사전학습의 상대 기여도가 OpenAI 사전학습보다 +0.087(95% 구간 [+0.069, +0.106]) 컸다 (0.179 대 0.092). 인코더는 ResNet-50 · OpenAI CLIP과 나머지 네 인코더의 두 층으로 나뉘었다.
- **구매 기록:** Marqo에서 희소 상품의 절대 기여도는 기존 상품보다 +0.021([+0.016, +0.027]), 신규 상품은 +0.016([+0.011, +0.022]) 컸다. 범용 SigLIP에서도 같았으며, 모든 인코더에서 같은 방향이었다.
- **ID 사용 방식:** 드롭아웃 없이(p=0) ID를 쓰면 기존 상품에서 Marqo의 상대 기여도가 0.167에서 0.126으로 줄었다 (차이 +0.041, [+0.020, +0.064]). 범용 SigLIP에서도 +0.031([+0.009, +0.052])이었다.

## 6. 결론 및 한계

사전 등록한 세 가설은 모두 지지되지 않았다. 같은 구조에서 패션 도메인 적응은 이미지 기여를 바꾸지 않았고, 선택한 설정의 상품 ID도 기존 상품에서 이미지 기여를 줄이지 않았다. 반면 탐색적 분석에서 이미지 기여는 인코더의 사전학습, 상품의 구매 기록 양, ID 사용 방식에 따라 크게 달랐다. 세 요인 모두 선행 연구 [1]의 조건, 즉 ImageNet 계열 특징, 기존 상품 중심 평가, ID를 그대로 쓰는 모델에서 이미지 기여가 작아지는 방향이었다. 이는 "이미지는 추천에 기여하지 않는다"는 결론이 이러한 조건에 의존할 수 있음을 시사하며, 향후 사전 등록된 검증이 필요하다.

**한계.** 첫째, 단일 데이터셋(H&M)과 한 가지 모델 구조로 실험했으며 [1]과 모델 · 데이터가 다르다. 둘째, 확증 검정의 정밀도가 제한적이다. H1과 H2의 97.5% 구간 폭이 각각 약 ±0.023과 ±0.025로, 소규모 효과에 대한 검출력이 낮음을 시사한다. 세 가설의 불지지는 "효과가 존재하지 않는다"가 아니라 "이 표본에서 통계적으로 유의미한 크기의 효과가 관찰되지 않았다"로 해석해야 하며, 소규모 효과의 확정적 배제를 위해서는 표본 확대나 정식 검정력 분석이 필요하다. 셋째, ID 모델은 상품 쪽에만 ID를 쓰고, 검증 성능이 ID 없는 모델보다 약 20% 낮아(과적합으로 판단) 강한 ID 모델이 아니다. 따라서 H2 불지지는 "ID가 일반적으로 이미지를 가리지 않는다"가 아니라 "이 약한 ID 설정에서는 이미지를 가릴 만큼 강하지 않았다"로 제한적으로 해석해야 하며, 강한 ID 모델(예: 정규화 · 조기 종료 도입)에서의 재검증이 필요하다. 넷째, 모델의 절대 성능(Recall@300 0.106)이 재구매 · 인기 기반 방법(0.257)보다 낮다. 다만 신규 상품에서는 인기 기반 방법이 추천하지 못한다. 다섯째, 사전학습 비교의 OpenAI와 LAION은 데이터 양과 구성이 함께 달라 원인을 특정할 수 없다. 여섯째, 패션 적응 인코더의 학습 데이터에 H&M 상품이 포함됐는지 확인할 수 없다. 일곱째, 2차 가설은 1차 결과를 본 뒤 등록했다.
