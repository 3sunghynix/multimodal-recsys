# 가설 · 사전 등록 · 평가 분할 · 결과 대응표

> 논문의 모든 확증 검정이 어느 사전 등록 커밋으로 동결됐고, 어느 테스트 주에서, 어떤 코드 · 노트북으로 계산돼, 어디에 결과가 있는지 정리한 표.
> 수치와 해석은 [실험기록.md](실험기록.md), 사전 등록 원문은 `paper/configs/`.

## 원칙

- **확증:** 사전 등록 파일을 커밋한 뒤에 학습 · 분석을 실행했다. 판정은 등록 파일의 기준(본페로니 보정 구간 하한 > 0)만 쓴다.
- **탐색:** 등록 파일의 `exploratory`에 적은 비교, 결과를 본 뒤 정한 비교, **이미 결과를 일부 본 테스트 주를 다시 쓴 후속 분석**은 모두 탐색으로 표시하고 95% 구간만 보고한다.
- **"등록 시 그 주에서 이미 본 결과"** 는 각 등록 파일의 `disclosure`를 옮겼다. 확증 비교 자체의 결과는 어느 경우에도 등록 전에 보지 않았다.
- 테스트 주: main 2020-09-16 ~ 22, s2 09-02 ~ 08, s4 08-19 ~ 25, s6 08-05 ~ 11. 네 분할은 26주 학습 기간이 대부분 겹치므로 독립된 재현이 아니라 테스트 주를 바꾼 반복이다.
