API 흐름 (디버깅용)
  • POST /search (FormData: q, file 선택, text_weight, k) → items의 상품 상세를 바로 표시
  • 텍스트·이미지 검색은 서버 기본 per_source_rank 결합 사용. 번역 결과는 query_en, 미번역 단어는 untranslated로 안내
  • GET /recommend/{user_id}?k=20 → {items: [id, …]} → GET /items?ids=…로 상세 조회
  • GET /images/{source}/{item_id}.jpg → 상품 이미지
