# dashboard — 관리자 · 사용자 화면 (담당: 김광석 설계, 구현 분담 미정)

## 관리자용

- **실험실:** 모델 3 ~ 4개 성능 비교 (오프라인 지표 · A/B 그룹별 지표 그래프)
- **알림 · 교체:** 지표가 기준 아래로 떨어지면 알림, 버튼으로 모델 교체 (`POST /models/{id}/activate`)
- **시뮬레이터 설정:** 페르소나 비율 · 규모 변경 후 결과 비교

## 사용자용

- 다중 브랜드 쇼핑 화면 (참고: KREAM), 텍스트 · 이미지 검색 업로드, 추천 영역
- (선택) 3D 핏 — MVP 이후 판단

## 정할 것

- 기술 선택: 관리자 화면은 빠른 구현을 위해 Streamlit, 사용자 화면은 React 등 — 와이어프레임 후 결정
- API는 `backend` (http://localhost:8000/docs) 를 그대로 사용
