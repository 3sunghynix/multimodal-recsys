## 1. 한 줄 결론

이미지 세밀 기여도는 원본 0.022448, 마스킹 0.025707이었다. 차이는 **+0.003260**, 95% 고객 부트스트랩 구간은 **[−0.001102, +0.007368]**으로, 예상 방향이나 차이는 불확실했다.

## 2. 질문·가설·분석 기준

- 질문: 동일 상품의 패턴 관련 단어를 가리면 이미지가 더 도움이 되는가?
- 가설: 마스킹 조건의 이미지 기여도 > 원본 조건의 이미지 기여도.
- 기여도: 구매 건 기준 Recall@300(C2) − Recall@300(C4).
- C2는 실제 이미지, C4는 동일 품목 내 섞은 이미지다.
- 핵심 비교: (masked C2 − masked C4) − (original C2 − original C4).
- 점추정과 95% 구간을 보고하며, 기존 테스트 데이터를 사용한 탐색적 결과다.

## 3. 배경

H_TextMention은 서로 다른 상품 집단을 비교했다. 이번에는 동일 상품의 입력 텍스트를 바꾸고 두 버전 모두 학습하여, 특정 패턴 단어를 가리는 조건에서 이미지 기여가 달라지는지 살펴봤다.

## 4. 실험 준비와 점검

- 상품명·품목·색상·설명이 합쳐진 text 열 전체를 대상으로 했다.
- 팀의 패턴 정규식에서 일반 단어 text를 제외했다.
- 최초 단어 삭제 방식은 문장을 깨뜨려 학습 전에 [MASK] 치환으로 변경했다.
- 원본 텍스트에서 규칙에 일치하는 패턴 상품 **5,972개**를 평가 집합으로 고정했다.
- 원본·마스킹 텍스트를 MiniLM으로 각각 임베딩했다.
- 원본 임베딩으로 PCA를 한 번 적합하고 두 버전에 공유한 뒤 L2 정규화했다.
- 출력 크기는 53,232 × 256, PCA 설명 분산은 약 0.9861이었다.
- 고정 상품의 평균 임베딩 변화 거리는 0.4589였다.

## 5. 실험 설계

| 항목 | 설정 |
| --- | --- |
| 데이터·분할 | H&M main |
| 모델 | ID 없는 Two-Tower |
| 인코더 | MiniLM + Marqo-FashionSigLIP |
| 입력 차원 | 텍스트 256 + 이미지 256 |
| 조건 | 원본/마스킹 × 실제/품목 내 섞은 이미지 |
| 학습 | seed 42·43·44, 각 8에폭, 총 12회 |
| 학습 쌍 | 각 실행 1,133,553쌍 |
| 평가 | 고정 상품 집합의 비재구매 구매; 구매 건 기준 Recall@300 |
| 통계 | 고객 단위 짝지은 부트스트랩 1,000회, seed 42 |
| 환경 | Colab Tesla T4; 세부 라이브러리 버전은 training_metadata 참조 |

원본 조건도 새로 학습했다. 상품 타워와 고객 구매 이력의 상품 표현 모두 해당 텍스트 버전을 사용한다.

## 6. 재현 방법

1. 복구 노트북을 새 Colab 세션에서 열고 DRIVE_ROOT를 설정한다.
2. 기본 RUN_TRAINING=False는 Drive에 남은 기존 실험 입력·12개 예측을 읽어 재채점한다.
3. 새로운 전체 재현은 RUN_TRAINING=True로 설정한다. 복구된 입력 준비 → 임베딩 → 12회 학습 → 평가 순으로 실행한다.
4. 새 출력은 kwangsuk_reproductions의 새 폴더에 저장한다.
5. 확인 값: 평가 상품 1,045개, 구매 5,420건, 고객 4,409명; 차이 약 +0.003260.

누락된 준비 셀은 frozen JSON과 대화에서 복구했다. 역사적 text_versions.parquet의 **바이트 동일성은 보장하지 않는다**. 라이브러리 버전과 표 직렬화에 따라 체크섬이 달라질 수 있으므로 새 재현 입력은 새 경로에서 생성한다.

## 7. 결과

고정 상품 5,972개 중 실제 평가 구매가 있는 상품은 1,045개였다. 구매 5,420건, 고객 4,409명이다.

### 조건별 점수

| text_version | real_recall_at_300 | shuffled_recall_at_300 | image_contribution |
| --- | --- | --- | --- |
| original | 0.070541 | 0.048093 | 0.022448 |
| masked | 0.069680 | 0.043973 | 0.025707 |

### seed별 차이

| seed | original_contribution | masked_contribution | difference |
| --- | --- | --- | --- |
| 42 | 0.030443 | 0.031550 | 0.001107 |
| 43 | 0.015129 | 0.024723 | 0.009594 |
| 44 | 0.021771 | 0.020849 | -0.000923 |

핵심 차이는 **+0.003260 [−0.001102, +0.007368]**다. 표시된 값의 반올림 때문에 마지막 자릿수의 차이가 있을 수 있다.

## 8. 해석

이미지 기여도가 평균 약 0.326%p 증가했지만 구간이 0을 포함한다. 두 seed는 양수이고 한 seed는 음수다.

실제 이미지 Recall은 0.070541 → 0.069680으로 감소했고, 섞은 이미지 Recall은 0.048093 → 0.043973으로 더 크게 감소했다. 기여도 증가를 추천 정확도 향상으로 해석하지 않는다. 텍스트만 조건과의 비교도 아니다.

## 9. 한계·주의

1. 기존 main 분할을 재사용한 탐색적 실험이다.
2. [MASK] 토큰 자체와 그 반복이 인코더에 영향을 줄 수 있다.
3. 정규식 밖 표현·상품명·소재 등의 시각적 단서는 남아 있다.
4. 전체 상품 및 고객 구매 이력 표현이 바뀌므로 개별 설명만의 직접 효과는 아니다.
5. 구간은 고정된 학습 결과에 조건부인 고객 재표집 구간이다. 학습 변동성을 완전히 반영하지 않는다.
6. 단일 데이터·분할·모델·인코더 설정에 한정된다.
