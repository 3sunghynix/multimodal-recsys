# 패턴 언급 규칙 표본 검토: 갱신된 판정 대조 결과

## 자료와 처리

갱신된 manual_review.csv와 sampling_key.csv를 review_id로 일대일 대조했다. 100개 상품 번호가 일치했고, 원본 상품명·설명·입력 텍스트가 보존되어 있었다. P033의 설명 및 전체 텍스트 판정은 U에서 0으로 변경되었으며, 미해결 판정은 없다.

## 설명 기준 분류 규칙과의 일치

| 자동 분류 집단 | 표본 수 | 불일치 수 | 관찰된 불일치율 |
|---|---:|---:|---:|
| 패턴 언급 있음 | 50 | 0 | 0% |
| 패턴 언급 없음 | 50 | 0 | 0% |

자동 분류 집단의 모집단 수는 양성 5,692개, 음성 10,962개다. 모집단 비율을 적용한 관찰 불일치율은 (5,692 / 16,654) × 0/50 + (10,962 / 16,654) × 0/50 = 0%다. 이는 이 표본에서 관찰된 값이며, 모집단 전체에 오류가 없음을 의미하지 않는다.

## 설명과 전체 입력의 차이

자동 음성 표본 50개 중 2개(4%)는 전체 입력에 명시적 패턴 언급이 있다.

- P001: 상품명의 CHECKS AND STRIPES
- P039: 상품명의 striped skirt

두 상품은 설명만을 대상으로 한 자동 규칙의 오분류가 아니다. 설명 미언급을 전체 입력에서 패턴 정보가 없다는 뜻으로 해석할 수 없다는 사례다. 이 4%는 층화 표본 중 자동 음성 집단에 해당하며, 카탈로그 전체 비율로 그대로 적용하지 않는다.

## 논문 해석

집단명은 설명(detail_desc) 내 패턴 언급 있음/없음으로 기술하는 것이 정확하다. 상품명·품목·색상·설명을 합친 text 전체에서 패턴 정보가 없는 집단으로 단정하지 않는다. text 전체를 대상으로 한 마스킹 실험과 분류 범위가 다르다는 점도 구분한다.

## 검토 절차 기록

초기 판정은 AI 보조로 작성되었고, 갱신 파일에서 P033이 수정되었다. 다만 모든 행의 메모에 여전히 human check pending 문구가 남아 있어, 사람의 전체 검증 완료 여부·담당자·확인일은 이 파일만으로 확인할 수 없다. 실제 사람이 확인한 범위와 날짜에 맞춰 최종 검토 기록을 보완한다. 독립적인 블라인드 수동 검증이나 인간-AI 간 독립 일치도를 수행했다고 표현하지 않는다.
