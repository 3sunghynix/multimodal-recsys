## 1. 한 줄 결론

패턴 상품의 비재구매 구매에서 **설명에 패턴이 언급된 상품의 이미지 세밀 기여도가 더 크게 관찰됐다.**

상품군을 통제한 ‘미언급 − 언급’ 기여도 차이는 **−0.013112**, 95% 고객 단위 부트스트랩 구간은 **[−0.020492, −0.006295]**였다. 포함된 상품군 4개와 학습 seed 3개에서 모두 예상과 반대 방향이었다.

## 2. 질문 · 가설 · 분석 기준

- **질문:** 텍스트 설명이 패턴 정보를 제공하지 않을 때 이미지가 더 도움이 되는가?
- **가설:** 패턴 상품에서 이미지 기여도는 ‘설명에 패턴 미언급’ 그룹이 ‘언급’ 그룹보다 크다.
- **분류:** 기존 `desc_mentions_pattern` 피처 사용.
- **이미지 세밀 기여도:** `Recall@300(C2) − Recall@300(C4)`
    - C2: 텍스트 + 실제 이미지
    - C4: 텍스트 + 동일 품목 내 섞은 이미지
- **비교 방향:** 미언급 그룹의 기여도 − 언급 그룹의 기여도.
- **분석 기준:** 차이의 점추정과 95% 고객 단위 짝지은 부트스트랩 구간 보고.
- 기존 테스트 결과를 재사용하므로 **사전 등록 확증 결과로 해석하지 않는다.**

## 3. 배경

팀의 큰 연구 질문은 “추천시스템에서 이미지는 텍스트와 함께 쓰일 때 언제·어디서·어떻게 도움이 되는가?”이다.

기존 패턴 대 무지 비교에서는 예상한 차이가 확인되지 않았다. 이번 분석은 패턴 상품 안에서도 설명에 패턴 정보가 있는지에 따라 이미지 기여가 달라지는지 살펴본다.

이미지가 텍스트의 부족한 정보를 보완한다면, 패턴 미언급 상품에서 기여도가 더 클 것으로 예상했다.

## 4. 분석 준비와 점검

### 4-1. 데이터 및 실행 확인

- 상품 테이블: **53,232개**
- 패턴 상품: **16,654개**
    - 설명 미언급: 10,962개
    - 설명 언급: 5,692개
- main 테스트 정답: **150,415행**
- C2·C4의 seed 42·43·44에 대해 `candidates.npy`, `users.npy` 존재 확인.
- 준비물 manifest의 **23개 파일 체크섬 일치** 확인.

### 4-2. 비교 규칙

- 평가 대상: 패턴 상품의 **비재구매 구매**
- 상품군별로 미언급·언급 두 그룹 모두 구매 **300건 이상**인 경우만 포함.
- 포함 상품군과 가중치는 모델별 성능을 계산하기 전에 구매 수로 결정.
- 두 그룹의 차이를 상품군별로 계산한 뒤, 해당 상품군의 두 그룹 합계 구매 수로 가중 평균.
- 별도 모델 학습 없이 기존 후보를 재채점.

이 규칙을 분석 셀 실행 전에 정의했지만, 별도의 사전 등록 기록은 없으므로 탐색적 분석으로 분류한다.

## 8. 해석

### 결과가 말해주는 것

- 예상과 달리 설명에 패턴이 언급된 상품에서 이미지 기여도가 더 크게 관찰됐다.
- 포함된 4개 상품군 모두 같은 방향이었다.
- 두 설명 그룹 모두에서 실제 이미지의 성능이 품목 내 섞은 이미지보다 높았다.

### 결과가 말해주지 않는 것

- 패턴 단어를 추가하면 이미지 기여가 증가한다는 인과적 결론은 낼 수 없다.
- 설명 미언급이 전체 입력 텍스트의 시각 정보 부재를 뜻하지 않는다. 상품명 등에 정보가 있을 수 있다.
- 이미지 기여도가 크다고 최종 추천 성능도 반드시 높은 것은 아니다. 언급 그룹은 모든 포함 상품군에서 섞은 이미지 조건의 성능이 더 낮았다.
- 텍스트만 사용하는 조건과 비교하지 않았으므로, 이번 결과를 그대로 “텍스트만 대비 개선량”이라고 부르면 안 된다.

## 9. 한계 · 주의

1. **탐색적 분석:** 기존에 살펴본 main 테스트 데이터를 재사용했다.
2. **설명 분류의 한계:** 키워드 기반 피처이며, 부정 표현·모호한 표현·전체 입력 텍스트의 정보를 완전히 반영하지 못할 수 있다.
3. **남아 있는 교란:** 상품군은 통제했지만 인기도, 상세 품목, 패턴 종류, 설명 길이 등의 차이는 남아 있다.
4. **표본 불균형:** 미언급과 언급 그룹의 구매 수가 다르며, accessories·shoes는 최소 구매 수 기준으로 제외됐다.
5. **제한된 범위:** H&M, main 분할, Marqo, Two-Tower 설정의 결과다.
6. **불확실성 범위:** 신뢰구간은 세 학습 seed의 결과를 평균한 뒤 고객을 재표집한 것이다. 학습 변동성 전체를 반영한 구간은 아니다.
7. **라벨 검토:** 외관 라벨의 팀 재검수 완료 여부와 설명 피처의 표본 정확도를 추가 확인해야 한다.
