## 1. 한 줄 결론

품목·이력 수 층을 조정한 high−low 이미지 기여도 차이는 **+0.006600**, 95% 고객 층화 부트스트랩 구간은 **[−0.009907, +0.022624]**다. 예상 방향이지만 차이는 불확실하다.

## 2. 질문·가설·분석 기준

- 질문: 어떤 고객에게 이미지가 더 도움이 되는가?
- 가설: 같은 품목에서 시각적으로 비슷한 상품을 구매하는 고객의 이미지 기여가 더 크다.
- 일관성: 과거 같은 품목 구매 상품의 Marqo 임베딩 평균 쌍별 코사인 유사도.
- 비교: 높은 일관성 기여도 − 낮은 일관성 기여도.
- 기여도: 고객별 평균 Recall@300(C2) − Recall@300(C4).
- 기존 데이터의 탐색적 비교이며, 점추정과 95% 구간을 보고한다.

## 3. 배경

상품·텍스트·인코더 조건을 살펴본 기존 실험에서 관점을 고객으로 확장했다. 시각적으로 일관된 이력이 이미지 기반 고객 표현에 더 유용할 것으로 예상했다. 측정값은 인코더 기반 구매 일관성이며 개인 취향의 직접 측정은 아니다.

## 4. 분석 준비와 점검

- 테스트 시작 전 구매만 사용했다.
- 고객·상품 중복을 제거하고 최근 50개 서로 다른 상품을 남겼다.
- 가장 많이 산 대표 품목을 선정했다. 동률이면 품목명 정렬 순서로 결정했다.
- 해당 품목에서 서로 다른 상품을 5개 이상 산 고객을 포함했다.
- 대표 품목 × 이력 수(5–9, 10–19, 20–50)로 층화했다.
- 층 내 유사도 상·하위 약 1/3을 선택했다. 각 그룹 최소 30명이다.

조건 충족 고객은 21,508명이다. 선택 그룹은 high 6,871명, low 6,870명으로 23개 층이었다. 평균 유사도는 high 0.540314, low 0.325322였다.

## 5. 실험 설계

| 항목 | 설정 |
| --- | --- |
| 데이터·모델 | H&M main, 기존 ID 없는 Two-Tower |
| 피처·예측 | 기존 Marqo 임베딩과 A/main C2·C4 |
| seed | 42·43·44; 추가 학습 없음 |
| 평가 구매 | 대표 품목의 비재구매 구매 |
| 평가 층 | 품목 × 이력 수 구간 |
| 최소 평가 표본 | 층의 high·low 각각 고객 30명 |
| 지표 | 고객별 Recall@300 → 층·그룹 평균 |
| 가중치 | 층별 high·low 합계 평가 고객 수 비율 |
| 통계 | 층·그룹 내 고객 재표집 1,000회, seed 42 |

실제·섞은 이미지 점수는 같은 고객의 쌍으로 유지한다. high·low는 서로 다른 고객 그룹이다. 앞선 텍스트 실험의 구매 건 기준 Recall과 집계가 다르다.

## 6. 재현 방법

1. 복구 노트북을 새 Colab 세션에서 열고 공유 Drive 경로를 설정한다.
2. 기본 REBUILD_GROUPS=False는 기존 Drive의 customer_groups.csv를 읽어 재채점한다.
3. 그룹까지 새로 만들려면 REBUILD_GROUPS=True를 선택한다. 과거 이력으로 그룹 구성 후 평가한다.
4. 새 출력은 kwangsuk_reproductions의 새 폴더에 저장한다.
5. 확인 값: 10개 층, 고객 3,311명, 구매 5,941건; 차이 +0.006600.

고객별 원본 그룹 파일은 ZIP에 포함되지 않았다. Drive 파일 또는 그룹 재구성에 필요한 원본 데이터가 있어야 전체 재채점이 가능하다.

## 7. 결과

대표 품목의 평가 구매가 있으며 최소 표본을 충족한 10개 층에서 고객 3,311명(low 1,617명, high 1,694명), 구매 5,941건을 평가했다.

| --- | --- | --- | --- |
| low | 0.158188 | 0.136134 | 0.022054 |
| high | 0.306022 | 0.277368 | 0.028654 |

### seed별 결과

기여도 차이는 **+0.006600 [−0.009907, +0.022624]**, 약 +0.66%p다.

## 8. 해석

높은 일관성 그룹에서 평균 이미지 기여가 더 컸지만 구간이 0을 포함한다. 두 seed는 양수, 한 seed는 음수이며 seed 42의 차이가 크다.

높은 그룹은 실제·섞은 이미지 조건 모두에서 전체 Recall이 높다. 높은 추천 성능과 이미지의 추가 기여를 구분해야 한다. 높은 전체 Recall만으로 이미지 효과가 더 크다고 판단하지 않는다.

## 9. 한계·주의

1. 기존 main 분할의 탐색적 결과다.
2. 유사도는 Marqo 기준이며 사람의 스타일 판단과 다를 수 있다.
3. 인기도·색상·유사 제품·구매 시점 등의 교란이 남아 있다.
4. 같은 이력 구간 안에서도 실제 이력 수가 다르다.
5. 테스트 주에 대표 품목을 구매한 고객만 평가한다.
6. 대표 품목 하나로 고객을 표현하며 표본이 작은 층은 제외된다.
7. 구간은 학습 변동성을 완전히 반영하지 않는다.
8. 단일 데이터·분할·모델·인코더 설정에 한정된다.

## 11. 이어받는 사람을 위한 다음 단계

1. 높은·낮은 그룹의 구매 이미지 표본을 확인한다.
2. 상품 인기도와 텍스트 유사성이 그룹 차이를 설명하는지 살펴본다.
3. 추가 seed·평가 기간은 범위를 먼저 고정하고 모두 보고한다.
4. 전체 성능과 이미지 기여도를 분리하여 보고한다.
