## 요약

- **신규 상품 (네 분할):** UME − 이른 결합(C2)은 기존 상품에서 +0.021 ~ +0.026(모두 구간 > 0), 신규 상품에서 −0.007 ~ +0.001(s6만 구간 < 0). UME − 이른 결합 × 2는 신규 상품에서 −0.009 ~ −0.017(main · s2 · s6, 모두 구간 < 0; s4는 C2 벡터가 없어 계산 불가). 즉 UME의 이득은 기존 상품에 한정된다는 s2 결과가 네 분할에서 재현됐다.
- **공동 학습 변형 (네 분할):** 합산 − C2 −0.0006 ~ +0.0001, 게이트 − C2 +0.0003 ~ +0.0007(모두 구간이 0 포함). UME는 합산보다 +0.020 ~ +0.024, 게이트보다 +0.019 ~ +0.023 높았다(모두 구간 > 0). 게이트 α 0.475 ~ 0.480 ± 0.022. main 결과(0.1051 · 0.1061 대 0.1056)는 3차 사전 등록(H4 불지지)과 일치한다.
- 참고(논문 미기재): 신규 상품 구간에서 게이트는 s2 · s4에서 C2보다 높았다(+0.0054 · +0.0057, 구간 > 0). main · s6에서는 구간이 0을 포함한다.
